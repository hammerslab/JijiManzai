# 遅咲きデビュー（大人になってから趣味を始める）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「釣りを始めた」＋サブ（竿 12 本 → ルアー 300 個 → ポケット 40 個のベスト → ボウズ対策 → 店内放送 → 人が入れる冷凍庫 → 道具を積んだら自分が乗れない → 道具だけ宅配便 → 次の趣味は漫才）
# オチ：次の趣味は「漫才」。マイクを 50 本そろえた → 叩いて「1 本で足りるだろ！ ここにあるだろ！」（舞台のセンターマイク）
# 技：エスカレーション（道具が増える）、天丼（竿が 12 本 → 13 本）、スカシの間（見つめ合う → 「50 本」）、伏線回収（形から入る → 漫才のマイク）
# 事実：時事ではなく、趣味を始める大人のあるある。「ボウズ」＝釣りで一匹も釣れないこと、「ルアー」＝魚に似せた疑似餌（釣りの一般的な言葉）
# 気をつけたこと：年齢で人を笑わない（ボケの年は出さない。ツッコミが冒頭で「始めるのに遅いなんてない」と肯定する）。笑うのはボケが道具ばかり買うずれだけ。釣り場の上手な人（じいの声）は「ちゃんとしている」側。店名・商品名は出さない
