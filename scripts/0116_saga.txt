# 佐賀県（都道府県シリーズの試し）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 2：「佐賀県の観光大使になりたい男」×「覚えたての佐賀弁」。ボケは外から来た人で、覚えたての語尾（〜ばい・〜けん・がばい）を何にでも付ける（抑揚は標準語のまま。まねなので不自然にならない）
# サブ（しょぼい → 大きい）：あいさつに全部「ばい」→ 日本一ののりで名刺を作る → 有明海の潮が引いて海を探す → 透き通った呼子のイカで皿だけ出てきたと思う → 有田焼の茶わんを毎日拝む → 「ばい」と「けん」をまぜる
# オチ：観光大使の名刺（のり）を 100 枚作ったが、おなかがすいて全部食べた → 見つめ合う → B!!!（伏線回収：のりの名刺）
# 技：天丼（ばい）、伏線回収（のりの名刺）、たとえツッコミ、見つめ合う（オチの前）
# 事実（2026-11-16 時点）：佐賀県は養殖のりの生産量が日本一。有明海は干満の差が最大 6m ほど。呼子のイカは透き通っていることで知られる。有田焼・伊万里焼・唐津焼の焼き物の県。佐賀の方言は「〜けん（〜だよ・〜だから）」「〜ばい」「がばい（とても）」を使う（All About、nap-camp、Saga dialect）
# 気をつけたこと：佐賀を「何もない」「どこ」といじらない。県のほうはちゃんとしている側で、ずれているのはボケの使い方だけ。方言は好きでまねしている向き（からかわない）。実在の店・会社・人の名前、有名な本や歌の題名は出さない
