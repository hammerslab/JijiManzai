# 早口言葉。男性コンビ。A＝ボケ（痩せたアフロ・淡々とゆっくり）／B＝ツッコミ（太ったモヒカン）
# 型 2：メイン「早口言葉」×「ゆっくりしか言わない男」＝遅すぎて、言っている間に早口言葉の中の世界が進む。サブ（生麦生米生卵が「遅口言葉」になる → 隣の客は、言い終わるころに帰っている → 東京特許許可局は「許可局」の前に窓口が閉まる → 相方が赤巻紙で噛み、ボケはゆっくりで噛まない → すもももももも、の途中で庭のすももが実り、近所に配る）
# オチ：「最後くらい、普通の速さで言え」→ ボケが急に 3 つ続けてすらすら言える →「早く、帰りたいから」→ B!!!「漫才を、早く終わらせたいだけだろ！」（スカシと緩急の逆）
# 技：天丼（言っている間に時間が進む）、エスカレーション（客が帰る → 窓口が閉まる → すももが実る）、立場の入れ替え（ツッコミが噛む）、緩急、見つめ合う（オチの前）
# 気をつけたこと：早口言葉はどれも昔からあるもの。噛む人や話すのがゆっくりな人をばかにしない（ゆっくりを自慢するボケのずれで笑う）
# 読み：早口言葉は全部 {表示|読み} でかなの読みを決めた（VOICEVOX が「生米」「東京特許許可局」などを読み違えないように）
