# 兵庫県（都道府県シリーズ）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 2：「兵庫の物産展を開きたい男」×「覚えたての兵庫の言葉」。ボケは外から来た人で、神戸の「〜とう（〜している）」をまだ始まっていない明日のことに使い、播州の「べっちょない（大丈夫）」を大丈夫じゃないときに言う（抑揚は標準語のまま。まねなので不自然にならない）
# サブ（しょぼい → 大きい）：明日のことに「開いとう」→ 準備ゼロで「べっちょない」→ レジに小野市のそろばん（足に敷いてすべる）→ 淡路島の玉ねぎは甘いから切っても泣かないと思った → 明石の東経 135 度の線の真上にテントを張り、右と左で時間がちがうと思う → 目玉に等身大の姫路城の模型
# オチ：物産展のお客さんがまだゼロ → 見つめ合う →「今、この漫才で、宣伝しとう」（「とう」を初めて正しく使う）→ B!!!（伏線回収：「とう」の使い方、物産展）
# 技：天丼（べっちょない）、伏線回収（「とう」）、ノリボケ（等身大）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：兵庫県は北が日本海、南が瀬戸内海に面する。世界遺産の姫路城、港町の神戸、淡路島（玉ねぎが有名）。清酒の生産量は日本一（県内の製造は全国の約 3 割。兵庫県の地場産業のページ・県の報道資料）。小野市はそろばんの生産量が日本一（全国の約 7 割。播州そろばん）。明石は日本の標準時の基準になる東経 135 度の線（子午線）が通る。神戸の言葉の「〜とう（〜とー）」は「〜している」（Wikipedia「神戸弁」、地球の歩き方）。播州弁の「べっちょない」は「大丈夫・問題ない」（TANOSU、神戸新聞の PR 記事）
# 気をつけたこと：震災にはふれない。県のほうはちゃんとしている側で、ずれているのはボケの使い方だけ。播州の「だぼ」などの悪い言葉は使わない。神戸牛などの地域ブランド名・実在の店・会社・人の名前は出さない。お酒は紹介で名前を出すだけ（ネタにしない）
