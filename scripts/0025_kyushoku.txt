# 給食が少ない。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「献立表の名前で、頭の中の給食がふくらむ」＋サブ（彩りハンバーグ → 海の幸たっぷり → 試食会で「写真と違う」 → イカが一つ → はかりと虫めがね → 季節のフルーツ → 栄養士さんに聞く → 家の夕飯の献立表を自分で書く）
# オチ：ボケが家の夕飯に「黄金色の、ふわとろ卵の、宝石箱」と名前を付けたら、中身は卵かけご飯で、家族全員が「写真と違う」と言った。「お前が一番、盛ってるだろ！」
# 技：伏線回収（「写真と、違う」→ 最後に家族から自分が言われる）、たとえツッコミ（座布団か）、ノリボケ（量を確かめる道具を持ち込む）、立場の入れかわり（盛っていたのはボケ）
# 事実：2026 年、学校給食の量が少ないのではという写真の投稿がネットで話題になった。物の値段が上がる中、国の栄養の基準は変わっておらず、学校や栄養士がやりくりして決まった栄養をとれるように作っている。2026 年 4 月から公立小学校の給食費の負担を軽くする取り組みが始まった（ファイナンシャルフィールド 2026 年の記事、港区「区民の声」への回答）
# 気をつけたこと：学校・給食を作る人・栄養士・子ども・保護者を責めない（B が「栄養はちゃんと決まっていて、やりくりして作ってる」と言い、栄養士さんは正しい側に置く）。献立表の写真はボケの頭の中だけにして、「写真と違う」のはボケの思い込み。給食費の制度の良し悪しは言わない。食べ物を粗末にしない
