# 茨城県（都道府県シリーズ）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 2：「茨城の日本一でフルコースを作りたい男」×「覚えたての茨城弁」。ボケは外から来た人で、「〜だっぺ（〜だろう）」を自分のことにまで付け、「ごじゃっぺ（でたらめ）」をほめ言葉だと思っている（抑揚は標準語のまま）
# サブ（しょぼい → 大きい）：「おなかすいただっぺ」→ 前菜のれんこんを穴からのぞく → スープは水戸の納豆の糸だけ → メインのあんこう鍋で「つるし切り」を自分がされる → デザートのメロンを「ごじゃっぺ」とほめる → ピーマンにメロンをつめる
# オチ：フルコースの店の名前 → 見つめ合う →「ごじゃっぺ」→ B!!!「でたらめの店」（伏線回収：ごじゃっぺ）
# 技：天丼（だっぺ）、伏線回収（ごじゃっぺ）、一拍空け、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：茨城県は、ピーマン・メロン・干しいも（かんしょ切干）・れんこんの農業産出額が全国 1 位（令和 6 年。茨城県の品目別産出額のページ、出どころは農水省「生産農業所得統計」）。水戸の納豆が知られる。あんこう鍋は冬の名物で、大きくぬるぬるしてまな板でさばきにくいあんこうを、つるして切る「つるし切り」がある（茨城県の広報「冬のお魚」特集、旅行記事）。方言「だっぺ」は「〜だろう」、「ごじゃっぺ」は「でたらめ・いいかげん」（ウィキペディア「茨城弁」）。（順位の数字はオチの芯にしない）
# 気をつけたこと：茨城を「何もない」「ランキング」でいじらない（魅力度の順位などは出さない）。県のほうはちゃんとしている側で、ずれているのはボケの使い方だけ。「ごじゃっぺ」はボケが取り違える向きで、人や県に向けて言わない。実在の店・会社・人の名前は出さない
