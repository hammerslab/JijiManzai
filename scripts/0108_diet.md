# 明日からやせる女

- お題：ダイエット
- コンビ：女性　ボケ・ボブ／ツッコミ・ギャル
- 長さ：2分52秒（VOICEVOX の声で作ったとき）

記号：〔間〕＝少し黙る、【叩く】【強く叩く】【思いきり叩く】＝手刀でツッコむ（効果音つき。頭の「えぐーー！」は自動で付く）、〈〉＝そこだけ声を変える

**2 人**　どうもー、よろしくお願いしますー！

**ツッコミ・ギャル**　ねえ、ダイエットって、したことある？ 食べすぎを、ちょっとひかえたり、体を動かしたりするやつ。無理しないで、少しずつ続けるのが、大事なんだって。

**ボケ・ボブ**　〔間〕私も、やってる。

**ツッコミ・ギャル**　お、いいじゃん。いつから？

**ボケ・ボブ**　〔間〕明日から。

**ツッコミ・ギャル**　まだ始まってないじゃん！

**ボケ・ボブ**　3年前から、明日から。

**ツッコミ・ギャル**　【叩く】えぐーー！ 3年も、明日が来てないじゃーーん！

**ボケ・ボブ**　でも、昔の人の、言葉も、守ってる。

**ツッコミ・ギャル**　どんな？

**ボケ・ボブ**　〔間〕「腹八分目に、医者いらず」〈おじいさんの声〉

**ツッコミ・ギャル**　あー、おなかいっぱいの、ちょっと手前でやめると、体にいい、ってやつね。

**ボケ・ボブ**　〔間〕8分おきに、食べてる。

**ツッコミ・ギャル**　【叩く】えぐーー！ 時間じゃないじゃーーん！ 一日じゅう、食べてるじゃん！

**ボケ・ボブ**　カロリーの、こともちゃんと、考えてる。

**ツッコミ・ギャル**　お、えらいじゃん。

**ボケ・ボブ**　お店で、「これ、サービスです」って、もらったものは、

**ツッコミ・ギャル**　うん。

**ボケ・ボブ**　〔間〕タダ。

**ツッコミ・ギャル**　うん。

**ボケ・ボブ**　〔間〕0円だから、0キロカロリー。

**ツッコミ・ギャル**　【叩く】えぐーー！ お金とカロリーは、関係ないじゃん！ タダでも、ちゃんと、カロリーはあるじゃん！

**ボケ・ボブ**　歩くのも、やってる。1日、1万歩。

**ツッコミ・ギャル**　すごいじゃん！ それは、本当に、えらい。

**ボケ・ボブ**　〔間〕歩数計を、扇風機に、つけてる。

**ツッコミ・ギャル**　扇風機が、歩いてるじゃん！

**ボケ・ボブ**　〔間〕1万歩の、ごほうびに、パフェを、食べた。

**ツッコミ・ギャル**　【強く叩く】えぐーー！ 歩いたの、扇風機じゃーーん！ ごほうびは、扇風機にあげなよ！

**ボケ・ボブ**　スマホの、カロリー計算の、アプリも、入れた。

**ツッコミ・ギャル**　食べたものを入れると、カロリーを、出してくれるやつね。

**ボケ・ボブ**　ケーキって入れると、カロリーが、高く出るから、

**ツッコミ・ギャル**　うん。

**ボケ・ボブ**　〔間〕「ふわふわ」って、入れた。

**ツッコミ・ギャル**　名前を、ぼかさないで！

**ボケ・ボブ**　〔間〕「ふわふわ、は、食べ物では、ありません」〈機械の声〉

**ツッコミ・ギャル**　アプリのほうが、ちゃんとしてるじゃん！

**ボケ・ボブ**　でも、ケーキは、食べていい日も、ある。

**ツッコミ・ギャル**　まあ、お祝いの日とかはね。誕生日とか。

**ボケ・ボブ**　世界の、どこかで、

**ツッコミ・ギャル**　うん。

**ボケ・ボブ**　〔間〕毎日、だれかが、誕生日。

**ツッコミ・ギャル**　まあ、そうだけど。

**ボケ・ボブ**　〔間〕だから、毎日、お祝いしてる。知らない人の。

**ツッコミ・ギャル**　【強く叩く】えぐーー！ 知らない人の誕生日で、食べないで！ 本人、何も知らないじゃん！

**ツッコミ・ギャル**　もう、明日からじゃなくて、今日から、一緒に、歩こうよ。散歩くらいなら、あたしも、付き合うからさ。

**ボケ・ボブ**　ほんと？

**ツッコミ・ギャル**　ほんと、ほんと。無理しないで、ちょっとずつね。

**ボケ・ボブ**　〔間〕じゃあ、始まる記念に、

**ツッコミ・ギャル**　うん。

**ボケ・ボブ**　〔間〕ケーキ、食べに、行こう。

**ツッコミ・ギャル**　お祝いが先なの！？

**ボケ・ボブ**　大丈夫。今日は、誕生日だから。

**ツッコミ・ギャル**　だれの？

**ボケ・ボブ**　〔間〕あなたの。毎日、あなたの誕生日って、ことにした。

**ツッコミ・ギャル**　【思いきり叩く】えぐーー！ 一年に、一回じゃーーん！ 毎日だったら、あたし、一年で、365歳になるじゃん！ もういいよ！

**2 人**　どうも、ありがとうございましたー！
