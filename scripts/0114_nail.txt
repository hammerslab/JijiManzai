# ネイル。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 2 寄り：メイン「新しいネイルが大事で叩けないツッコミ」×「それを知って、いっぱいボケるボケ」。ボケのネイルのサブ（油性ペンで黒くぬる → 爪に買い物のメモ、10 本でカレーの材料 → ネイルサロンを開いたら、お客は近所のねこで看板メニューは爪切り → ストーンに河原の石）
#   途中で役が入れ替わりかける（ツッコミがネイルに見とれる → ボケが低い声で「なんでじゃーん」→ ツッコミがボケをやってみて「……知ってる、じゃん」）
# オチ：「叩くのは手刀で、手の横だから、爪は当たらない」とボケが教える → 見つめ合う → B!!!「早く言ってじゃーーん！」（一日がまんしていた分、いちばん強く）
# 技：すれ違い（叩けない理由）、ノリボケ（叩かれないなら、いっぱいボケる）、役の入れ替え、スカシ（ツッコミのボケ）、伏線回収（手のひら・手首でかばう → 手刀なら爪は当たらない）、見つめ合う（2 回）
# 叩く絵：台本の B! はいつもどおり B が A を手刀で叩く絵になるので、セリフで「手のひらで、セーフ」「手首で、セーフ」と合わせる
# 気をつけたこと：ネイルやサロンをけなさない（ツッコミのネイルは「かわいい」と認める）。サロンや商品の名前は出さない。ねこにひどいことをしない（爪切りだけ）
