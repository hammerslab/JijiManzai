# 滋賀県（都道府県シリーズ）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 2：「滋賀を自慢したい男」×「覚えたての滋賀の言葉」。ボケは滋賀の人ではないのに滋賀を自慢したくて、彦根のほうの「〜ほん（自信をもって言い切る）」を、自信満々で間違えるときにも付ける。「だんない（大丈夫）」も使う
# サブ（しょぼい → 大きい）：琵琶湖は海より大きいほん → 滋賀県をピザにたとえると 1 切れが水 → 大阪の友だちに「それ、滋賀の水だほん」と言い続ける → 信楽焼のたぬきのとなりに自分も立つ → 近江商人の「三方よし」が「俺よし、俺よし、俺よし」
# オチ：なんでそんなに自慢したいのか → 恩があるほん → 見つめ合う → 京都に住んでいて、毎日琵琶湖の水を飲んでいる → B!!!（伏線回収：琵琶湖の水）
# 技：天丼（ほん、琵琶湖の水）、たとえ（ピザ）、伏線回収（水）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：琵琶湖は日本一大きい湖で、滋賀県の面積の約 6 分の 1（滋賀県「琵琶湖の概要」）。琵琶湖の水は淀川流域の約 1450 万人が使い、京都市の水道（山間部を除く）は琵琶湖の水を疏水で引いている（滋賀県、京都市上下水道局）。信楽焼のたぬきは笠・とっくりなどに 8 つの縁起があるとされる（滋賀県の広報）。近江商人の「三方よし」は売り手よし・買い手よし・世間よし（滋賀県・守山市の資料、大学の論文）。近江牛。滋賀の言葉の「〜ほん」は彦根を中心に、自信をもって念を押す・言い切るときの語尾（明日は晴れるほん）、「だんない」は「大丈夫・差し支えない」（近江弁の記事）
# 気をつけたこと：滋賀を「何もない」「京都の…」といじらない。琵琶湖の水を「止める」などの、よその県とけんかする向きのネタは使わない（自慢しすぎるのはボケだけ、相手の友だちも悪くない）。県のほうはちゃんとしている側で、ずれているのはボケの使い方だけ。方言は好きでまねしている向き（からかわない）。実在の店・会社・人の名前、テレビ番組の名前は出さない
