# 福島県（都道府県シリーズ）。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 2：「福島の名物になりたい女」×「覚えたての福島弁」。ボケは、ていねいにお願いする「〜くなんしょ（〜してください）」を、何でもていねいに言えばいいと思って使い、「んだない（そうだね）」で自分に相づちを打つ（抑揚は標準語のまま）
# サブ（しょぼい → 大きい）：「帰ってくなんしょ」→ 赤べこになって何を聞かれてもうなずく（プリンを食べたのがばれる）→ 起き上がり小法師になって、家族の人数より 1 回多く転ぶ → 大内宿のねぎそばが気に入り、ケーキもねぎで食べる → 喜多方の朝ラーから昼ラー・夜ラー・夜中ラー
# オチ：名物の芸「起き上がり小法師」で「思いっきりたたいてくなんしょ」→ 見つめ合う → B!!! で飛んで、起き上がってこない（伏線回収：起き上がり小法師・くなんしょ）
# 技：天丼（くなんしょ）、伏線回収（起き上がり小法師）、ノリツッコミ寄り（ラーメン）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：福島県は東北のいちばん南。会津の赤べこは首が揺れる張り子の牛で、病よけの縁起物（nippon.com、国交省の観光案内文）。起き上がり小法師は会津の縁起物で、家族が増えるようにと家族の人数より 1 つ多く買う習わし（福島県の観光 PR ページ、まっぷる）。大内宿のねぎそばは、長ねぎ 1 本を箸のかわりにして、かじりながら食べる（観光・グルメ記事）。喜多方ラーメンは日本三大ラーメンの一つで、朝からラーメンを食べる「朝ラー」の文化がある（nippon.com、るるぶ）。方言「〜なんしょ」は「〜してください」（してくなんしょ）、「〜（ん）だない」は「〜だね」（ウィキペディア「福島弁」）
# 気をつけたこと：震災・原発にはふれない（名物と名所の楽しい回）。福島を「何もない」といじらない。県のほうはちゃんとしている側で、ずれているのはボケの使い方だけ。赤べこ・起き上がり小法師は縁起物として茶化さず、ボケがなりきりすぎるだけ。実在の店・会社・人の名前は出さない
