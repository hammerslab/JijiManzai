# 三重県（都道府県シリーズ）。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 2：「三重の名物を全部やりたいのに、『全部、しやん（しない）』と言ってしまう女」×「覚えたての三重の言葉」。ボケは外から来た人で、三重の「〜やん」（見やん＝見ない、しやん＝しない）をギャルの「じゃん」の仲間だと思い、「全部、しやん」と言ってしまう。伊賀・伊勢のやさしい命令「〜さ（〜しなさい）」も出てくる
# サブ（しょぼい → 大きい）：「全部、しやん」で、やらない宣言 → 伊勢うどんを筆にして習字 → 伊賀で忍者のかくれる術、心だけかくれる → 海女さんになりたくてプールでアワビを探し、「上がりさ」とやさしく追い出される
# オチ：残っている名物は伊勢えびと松阪牛 → 見つめ合う →「高いから、しやん」→ B!!!（伏線回収：「しやん」の使い方が、そこだけ合っている）
# 技：言い間違い・勘違い（やん＝じゃん だと思う）、天丼（しやん）、伏線回収（しやん）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：三重県は伊勢湾に面し、伊勢神宮、伊勢えび、松阪牛、伊賀の忍者などで知られる。伊勢うどんはふつうの倍ほど太くやわらかい麺に、黒いたれをからめて食べる郷土料理（農水省の子ども向け食育ページ、観光三重）。（真珠の養殖のくだりは尺のために外した）鳥羽・志摩は海女の人数が日本一多い地域（三重県）。三重の言葉の「〜やん」は打ち消し（見やん＝見ない、しやん＝しない。2 拍の一段動詞やサ変・カ変に付く）、伊賀・伊勢の「〜さ」は連用形に付くやわらかい命令（書きさ＝書きなさい）（大阪大学の伊賀方言の論文、三重弁の記事）
# 気をつけたこと：三重を「関西か東海か分からない」「どこ」といじらない。伊勢神宮は紹介だけで、からかわない。県のほうはちゃんとしている側で、ずれているのはボケの使い方だけ。方言は好きでまねしている向き（からかわない）。お風呂や海で息を止めるまねはさせない（プールで探すだけ、すぐ上がる）。伊勢えび・真珠の順位の数字は出さない。実在の店・会社・人の名前、お菓子の商品名は出さない
