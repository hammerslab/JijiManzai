# 天気予報。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「天気予報の言葉を、そのとおりに受け取りすぎる男」＋サブ（降水確率 50% で、折りたたみ傘を半分だけ開く → 10% は傘のキーホルダー、90% は傘 9 本 → 「一時雨」を時刻だと思い、1 時ちょうどに傘を開いて 1 時 1 分に閉じる → 「所により雨」の「所」を地図で探す → 洗濯指数 100 で、冷蔵庫の中身まで干す → 自分で天気予報を出す。毎日「降水確率 50%」で、外れたことがない）
# オチ：「帰りは雨。降水確率 100%」→ 傘がない相方に「半分、入れてあげる」→ B!!!「半分しか開かないやつだろ！」（伏線回収：半分の傘）
# 技：伏線回収（半分の傘 → オチ）、エスカレーション（10% → 50% → 90%）、言い間違い・勘違い（一時雨・所により）、スカシ（外れたことがない → 当たったこともない）、見つめ合う（オチの前）
# 気をつけたこと：気象予報士さんや天気予報をけなさない（おかしいのはボケの受け取り方だけ）。番組や会社の名前は出さない。台風の回（0013）の「傘を逆さにさす」とはかぶらないようにした
