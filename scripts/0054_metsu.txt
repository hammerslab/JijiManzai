# 「〇〇すぎて滅」。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 1：メイン「何にでも『滅』と言う」＋サブ（パンが焼けすぎて滅 → 滅の段階：子猫 1 匹で滅・3 匹で全滅・5 匹で消滅 → 信号が点滅しすぎて滅・赤で幻滅 → 電車が遅れすぎて滅（2 分）→ 返事を「滅」だけにする（店員さんが訳してくれる）→ 相方のツッコミは「不滅」）
# オチ：「あんたのツッコミ、うますぎて、不滅」と褒めたと思ったら「一生、私が叩かれる。……滅」。叩いて「そっちの滅じゃーーん！」
# 技：言い間違い・勘違い（滅の熟語で遊ぶ：全滅・消滅・点滅・幻滅・不滅）、すれ違い（B は「いい気持ち」の滅、A はほろびる滅）、エスカレーション、スカシ（不滅でほめられたと思わせる）
# 事実：「〇〇すぎて滅」＝好きすぎる・かわいすぎるなど、いい気持ちがあふれて言葉にならないときに使う SNS の言い回し（ひらがなタイムズ、チケット流通センターの解説記事）。「滅」の由来ははっきりした資料がないので、台本では言わない
# 気をつけたこと：言葉を使う人を笑わない（B も言葉の意味を調べて、正しく使えばいいと言う）。店員さんは「ちゃんとしている」側。全滅・消滅は災害の話にしない（子猫を見たときの気持ちの段階だけ）
