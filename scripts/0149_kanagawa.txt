# 神奈川県（都道府県シリーズ）。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 2：「神奈川の歌を作りたい女」×「覚えたての神奈川の言葉」。ボケは外の人で、自分で作る神奈川の歌（有名な歌ではない、ボケのオリジナル）の歌詞に、覚えた「〜べ（〜しよう・〜だろう）」「〜だべ（〜でしょ）」、湘南の「〜べよ」、昔の言葉の「でーこ（大根）」を入れすぎる（抑揚は標準語のまま）
# サブ（しょぼい → 大きい）：1 番は「べ」できれいにまとまる → 小田原のかまぼこを取り寄せて、板でリズム・中身をマイクに → 2 番の三浦の大根が「でーこ、でーこ」でほぼ掛け声 → 3 番の湘南が「べよ、べよ、べよ」で鳥の鳴き声 → 4 番の箱根の温泉に、湯気の音「もわー」を入れる
# オチ：最後の歌詞「みんなで、神奈川に、行くべ」で、きれいにまとまる → でも、神奈川に行ったことがない → 見つめ合う → B!!!、ツッコミが「一緒に行くべ」と言ってしまい、うつる（伏線回収：〜べ＝〜しよう）
# 技：天丼（べ）、エスカレーション（べ → でーこ → べよ → もわー）、伏線回収（行くべ）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：神奈川県は東京のとなり。港町の横浜、鎌倉の大仏（国宝）、箱根の温泉、江の島などが知られる（神奈川県、高徳院の案内、神奈川県観光協会）。小田原はかまぼこの町で、旧東海道沿いに専門店が集まる（神奈川県観光協会ほか）。湘南のしらす（神奈川県観光協会）。三浦半島（三浦・横須賀）は大根の産地（農林水産省「神奈川県の農林水産業の概要」令和 7 年版）。神奈川の言葉：「〜べ」（〜しよう・〜だろう）、「〜だべ」（〜でしょ？ と同意を求める）、「〜べよ」（湘南に多い）、「でーこ」（大根。秦野のあたりなどの昔の言葉）（Wikipedia「神奈川県方言」：田中ゆかり『ふるさとのことば 神奈川県』などを参照、FUN! JAPAN）
# 気をつけたこと：神奈川を「東京のおまけ」といじらない。有名な会社・商品・歌の名前は出さない（歌はボケが作るもの）。大仏・お寺はネタにしない（名前を出すだけ）。県のほうはちゃんとしている側で、ずれているのはボケの歌詞だけ。温泉で騒ぐのはすすめない（ボケは行ったことがなく、想像で書いている）
