# 婚活。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 1：メイン「婚活アプリの条件」＋サブ（優しい人 → おにぎりの具は昆布 → 返信は 3〜5 分 → 傘は右手 → 120 個で 0 件 → 昆布か、おかか → 「一緒にいて楽」も条件に → 「検索条件に引っかからない人」で検索 → 条件に 1 つも当てはまらない人）
# オチ：どの条件にも引っかからない人＝ツナマヨ好き・返事は 1 秒・傘を忘れて人の傘に入る＝ツッコミ本人。「あたしじゃーーん！ 婚活じゃなくて、友達じゃん！」
# 技：天丼（「0件だった」→「でしょうね」を 3 回。3 回目は B が先に言う）、伏線回収（B が自分の好みを何気なく言っておく → オチで全部当てはまらない人＝B）、たとえツッコミ（面接か）
# 事実：結婚した人が相手と出会った場所は、マッチングアプリが 25.1% で一番多い（こども家庭庁の調査。東京商工リサーチ「TSRデータインサイト」2026 年の記事より）
# 気をつけたこと：婚活をする人・アプリで出会う人・相手をからかわない。条件は年収・身長・見た目など人を値踏みするものは使わず、ボケ本人のこだわり（おにぎりの具・返信の速さ・傘の手）だけにした。友達の助言（一緒にいて楽な人）は正しい側に置き、ずれるのはボケだけ。アプリの名前は出さない
