# 台本

漫才の台本を置くところ。**台本・声・動画・サムネ・ショートの名前は、すべて `<番号>_<名前>`**（例：`0001_m1`）。番号は 4 桁（0001〜）で、KEYWORDS.md のキーワードの頭に付けた番号と同じ（[番号のルール](#番号のルール)）。1 本につき 2 つのファイルがある。

- `<番号>_<名前>.md` … **読む用**。役名・間・叩くツッコミ・声の変わり目を言葉で書いたもの（`.txt` から自動で作る。直接は直さない）
- `<番号>_<名前>.txt` … **音声と動画を作る元**。直すのはこちら（書き方は `proto/hacker.txt` の頭、決まりごとは `docs/SCRIPT_GUIDE.md`）
- `<番号>_<名前>_end.txt` / `_end.md` … その回の**エンディング**（チャンネル登録を頼む掛け合い。ボケのひとことを回ごとに変える。ない回はコンビ共通の `proto/ending_*.txt`）

## 番号のルール

- **台本を作った時点で**、KEYWORDS.md のそのキーワードの頭に、次の番号を付ける（0001 から**作成順**。数千まで足りるよう 4 桁）。台本がまだのキーワードには付けない
- KEYWORDS.md の書き方は `✔0001 M-1　動画：2026/10/20 19:00　ショート：2026/10/21 12:00 — ネタの概要`。YouTube に上げたら、キーワードのあとに動画の公開日時を、ショートも上げたらそのあとにショートの公開日時を足す（まだなら日時なし。✔ は動画・ショート・サムネの準備ができて確認が済んだもの）
- ファイルの名前は `<番号>_<名前>`（名前は英字の短い呼び名）。台本 `scripts/0001_m1.txt`、声 `build/0001_m1/`、エンディング `build/0001_m1_end/`、動画 `build/anim/0001_m1.mp4`、ショート `build/anim/0001_m1_short.mp4`
- 番号は欠番にしない・使い回さない。台本を作り直しても番号は同じ。1 つの動画にまとめたキーワード（例：ハッカーと不正アクセス）は、同じ番号を書く
- 次の番号は、この表の一番下の番号に 1 を足す
- （2026-10-21 利用者の指示。それまでの 20 本は、公開した順に 0001〜0005（M-1・チャッピー構文・ドパガキ・麻辣湯・インフルエンサー）、そのあとは台本を作った順に 0006〜0020 にした。M-1 が最初に公開したので 0001）
- YouTube の題名には番号を入れない（番号は内部の管理用）

## 作り方

```bash
python proto/synth.py scripts/<番号>_<名前>.txt --backend voicevox   # 声（VOICEVOX を起動しておく）
python proto/synth.py scripts/<番号>_<名前>_end.txt --backend voicevox   # その回のエンディングの声
python proto/vv_kana.py scripts/<番号>_<名前>.txt                    # 読みをカナで確かめる（build/kana/）
python proto/script_md.py scripts/<番号>_<名前>.txt                  # 読む用の .md を作り直す
```
