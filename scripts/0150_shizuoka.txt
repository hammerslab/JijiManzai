# 静岡県（都道府県シリーズ）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 2：「静岡のお土産を選びすぎる男」×「覚えたての静岡の言葉」。ボケは旅行から帰ってきた外の人で、覚えた「〜だら（〜だろう）」を自分のことにまで付け、「やっきりする（腹が立つ）」をわさびに使い、「いいにする（もうやめにする・それで手を打つ）」を「いいのにする」と取り違える（抑揚は標準語のまま）
# サブ（しょぼい → 大きい）：お土産選びで帰りの電車がなくなる → お茶の試飲を全部して、おなかがいっぱい → わさびを丸ごとかじって選び、わさびに「やっきり」→ 駿河湾の桜えびから、いちばんきれいな 1 匹を 3 時間で選ぶ → 黒はんぺんのだし粉を、お土産全部にかける → 「いいにしろ」が「全部いいのにする」
# オチ：富士山は見られなかった → お土産屋さんの窓からずっと見えていたのに「箱の絵だら」と思っていた → 見つめ合う → B!!!（伏線回収：〜だら、お土産屋さんから出ていない）
# 技：天丼（だら）、言葉の取り違え（いいにする → いいのにする）、伏線回収（お土産屋さんにずっといた・だら）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：静岡県はわさび栽培の発祥の地（静岡市の有東木）で、わさびの産出額は全国 1 位。桜えびは国内では駿河湾だけでとれる（漁獲量 1 位）。温室メロンの収穫量、かつおの漁獲量も全国 1 位（農林水産省「静岡県の農林水産業の概要」令和 7 年版・2026 年版、静岡県）。お茶は全国有数の産地（荒茶の生産量は 2024 年に鹿児島県が 1 位、静岡県が 2 位になったので、日本一とは言わない）。静岡おでんの黒はんぺんは、イワシなどを骨ごとすり身にした練り物で、だし粉（サバ節・イワシの煮干しの粉）と青のりをかけて食べる（観光ガイド各種）。静岡の言葉：「〜だら」（〜だろう。県内全域）（NEWT）、「やっきりする」（腹が立つ・いらいらする）、「いいにする」（中止・妥協・許容・中断の 4 つの意味）（静岡新聞「あなたの静岡新聞」2025 年・2026 年の記事）
# 気をつけたこと：静岡を「通過するだけの県」「横に長い」といじらない。有名な会社・商品・お菓子の名前は出さない（お土産は「お茶」「わさび」「桜えび」のような一般の名前で）。富士山は県の宝として出し、からかわない。災害（噴火など）にはふれない。県のほうはちゃんとしている側で、ずれているのはボケの選び方と言葉だけ
