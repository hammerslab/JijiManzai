# ラーメンの行列。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「ラーメンより、行列のほうが好きな男」＋サブ（前の人の背中でスープのにおいを感じる → 先頭が近づくとさびしくなり、食べずに最後尾へ戻る。これを「替え玉」と呼ぶ → 7 周目でお店の人に気づかれ「はじめてです」→ 麺の固さを聞かれて「列はバリカタで」→ 「最後尾」の札を持ったまま 2 周目に行ったら、列がついてきて商店街をひとまわり → 味は知らないのに口コミ「列ののどごしがいい」）
# オチ：閉店後に大将が 1 杯作ってくれて、やっと食べる → 次の日から、大将も俺のうしろに並ぶようになった → B!!!「大将が並んだら、誰が作るんだよ！」
# 技：言葉遊び（替え玉・バリカタ・のどごしを列に使う）、エスカレーション（2 周目 → 7 周目 → 列がついてくる → 大将まで並ぶ）、たとえツッコミ（パレードか）、スカシ（いい話かと思わせる）、見つめ合う（オチの前）
# 気をつけたこと：店の名前は出さない。お店の人や並んでいるほかのお客さんをけなさない（迷惑なのはボケだけ、大将はやさしい側）。ファストパスの回（0030）の「どの列が早いか計算する」とはかぶらないようにした
