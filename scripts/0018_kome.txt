# 米の値段。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「米の値段」＋サブ（毎朝米の値段を見る → 高いときにわざわざ買う → 米マウント → 米ソムリエ → 米をおかずに米 → 一粒ずつ「いただきます」 → 新米＝新人 → 値下がりがさみしい → ベランダのバケツ稲）
# オチ：半年かけて育てたお茶わん一杯を相方にくれる……と思ったら「一杯、4257円です」（去年の値段を回収）
# 事実：2025 年は米の値段が大きく上がり、2025 年 9 月末のスーパーの平均は 5kg で約 4,257 円。2026 年の新米は 5kg 3,000 円前後で、割り込むかもという予想（予想値。台本では「予想もある」と言う）
# 農家や、値上がりで困っている人を笑わない。笑うのはボケの米への執着と米マウント。バケツ稲で「農家の人ってすごい」と、作る側を「ちゃんとしている」側に置く
