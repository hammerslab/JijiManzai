# インバウンド。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「道を聞かれた地元民が、翻訳アプリに頼る」＋サブ（アプリにお辞儀 → アプリが観光のおすすめまで話す → 実は道を知らない → 旅行の人に道と町の歴史を教わる → 日本語から日本語に翻訳して練習 → 「道、聞いてください」の札 → 劇場まで連れてきてもらう）
# オチ：劇場まで案内してくれた旅行の人が、客席で、漫才を翻訳アプリで聞いている。叩いて「今の全部、訳されてるのかよ！」
# 技：エスカレーション（案内する → 案内される → 連れてきてもらう）、天丼（駅の反対側に行ったことがない）、伏線回収（「駅の反対側」→ 劇場も反対側）、ノリボケ気味の過剰（札を下げて駅前に立つ）
# 事実：2026 年 7 月の訪日客は 344 万 2100 人で、7 月として過去最多（日本政府観光局の推計。トラベルボイス 2026-08-19）。台本では「この夏も、ひと月に 300 万人以上」とだけ言う
# 気をつけたこと：外国の人・特定の国を笑わない。国名は出さない。旅行の人は、調べてきていて親切な「ちゃんとしている」側。笑うのは、地元のことを知らない地元民のボケだけ
