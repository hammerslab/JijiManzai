# 「びっくりした、〇〇かと思った」。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 1：メイン「びっくりした、〇〇かと思った」＋サブ（茶色いバスタオル＝クマ → 赤い傘＝フラミンゴ → 落ち葉＝コロッケ → 枯れ尾花の逆（ススキ＝ほうき） → 掃除ロボット＝カメ → 冷蔵庫のプリン＝プリン → 窓に映った自分＝座敷わらし → 驚かせても驚かない → 相方＝相方）
# オチ：舞台の袖で金髪の人が来て「びっくりした、相方かと思った」→ 合ってる（プリンの天丼）。叩いて「相方じゃーーん！」
# 技：天丼（「びっくりした、〇〇かと思った」の型・当たっているのに驚く）、スカシ（B が驚かせても、間を置いて「あんたかと思った」）、伏線回収（プリン → 相方）
# 事実：時事ではなく、言い回しのあるある。「幽霊の正体見たり枯れ尾花」は昔からのことわざ（怖いと思って見たら、枯れたススキだった）。事実に頼らない作り
# 気をつけたこと：見間違えるのはボケ本人だけ。相方の見た目（体型）はネタにしない（金髪は「誰が来たか」の目印だけ）。窓に映るのはボケ本人
