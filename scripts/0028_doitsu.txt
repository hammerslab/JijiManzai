# 同一労働同一賃金。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「同一労働同一賃金」＋サブ（このコンビも同一労働 → ギャラを多くもらうため仕事の違いを探す → アフロの髪の量 → セリフの文字数は B が多い → ゆっくりしゃべるから時間で多い → 袖からマイクまで 3 歩多い通勤手当 → アフロに住む鳥の住宅手当・家族手当 → 叩かれ手当 → B も叩き手当で結局同じ額）
# オチ：違いを探しつくして手当を足したら、2 人とも同じ額に戻る。納得したふりで「鳥のエサ代も、半分ずつ」→ B!!!
# 技：エスカレーション（違いの探し方がだんだん苦しくなる）、伏線回収（アフロの鳥 → オチのエサ代）、すれ違い（住宅手当をもらう側のはずが大家になる）
