# 歯医者（時期に関係のない話題）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 2：歯医者 × 学校の授業（「痛かったら手を上げて」で手を上げ、授業のように発言する男）。サブ（口も開けないうちに手を上げる →「先生、質問です。歯ブラシは何本まで」→ 痛くなったときのためにずっと上げておく →「大きく開けて」で両手ばんざい → 受付でも手を上げて当てられるのを待つ → 宿題の歯みがきも手を上げながら、お母さんが当ててくれる）
# オチ：「今、ちょっと痛い」→ 歯ではなく「腕」→ B!!!「手を上げすぎだよ！」（伏線回収：痛かったら手を上げる → 上げすぎて痛い）
# 技：型 2 のずれ（歯医者を教室だと思う）、たとえツッコミ（授業か・遠足のおやつか・合格発表か）、天丼（手を上げる）、見つめ合う（オチの前）
# 気をつけたこと：歯医者に行くことをこわがらせない。治療の痛い場面は出さない。先生も受付の人もやさしく、ちゃんとしている側（ボケが勝手に手を上げているだけ）。定期検診と毎日の歯みがきは、よいこととして言う
