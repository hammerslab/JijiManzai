# 持ち家？賃貸？。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 1：メイン「家を買うか借りるか」＋サブ（持ち家＝壁に穴をあけたい → 賃貸＝気軽に引っ越せる → 35 年ローンとサブスク → 修理と電球 → 広さ（小さいから押し入れ） → 今の家は家賃ゼロ・ごはん付き（スルー） → 内見の予約フォームの「今の住所」）
# オチ：内見の予約に今の住所を書こうとして、住所が「あんたの家」＝ずっとツッコミの家に居候していた。どっちでもなく「居候」。B!!!「あたしの家じゃーーん！」
# 技：スルー（「今の家は、家賃ゼロで、ごはんも出てくる」→ B が実家だと思って流す → オチで回収）、伏線回収（冷蔵庫のプリンが減る／「押し入れで、十分」→ 住んでいたのはツッコミの家の押し入れ）、天丼（「どっちにも、いいところがある」）、見つめ合う（オチの前）
# 事実：住宅価格の上昇が続き、「持ち家か賃貸か」の論争があらためて話題。2026 年の公示地価は住宅地の全国平均が 5 年連続の上昇（現代ビジネス、2026）。金利の上昇も議論の材料に。台本では数字を使わず「家の値段も上がってて、よく話題になる」とだけ
# 気をつけたこと：持ち家・賃貸のどちらも否定しない（B が毎回「どっちにも、いいところがある」と両方を立てる）。おかしいのはボケの選び方の理由だけ。居候の相手はツッコミ本人なので、誰かを笑いものにしない。会社名・地名は出さない
