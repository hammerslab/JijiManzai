# 型 2：「岡山県民になりきる男」×「覚えたての岡山弁」。ボケは外から来た人で、覚えたての語尾「〜じゃ」と「でーれー・ぼっけー（すごい・すごく）」を場面に合わない使い方をする（抑揚は標準語のまま。まねなので不自然にならない）
# サブ（しょぼい → 大きい）：「晴れじゃ」を毎日言って天気予報を見ない → 青信号に「でーれー」→ 白桃を赤ちゃんのように抱っこして席をゆずられる → マスカットを指輪にしてしわしわ → 倉敷の川舟を降りず船頭さんが交代 → 児島のジーンズでパジャマもシーツも
# オチ：白桃をまだ抱っこしている → 割らずに待っているのは、中から男の子が出てくること → 見つめ合う → B!!!（伏線回収：白桃の抱っこ／岡山にゆかりの昔話）
# 技：天丼（晴れじゃ）、伏線回収（白桃）、たとえツッコミ（干しぶどうの指輪）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：岡山県は中国地方の東部。降水量1mm未満の日が全国でいちばん多く（気象庁の平年値）「晴れの国」と呼ばれる（岡山県）。清水白桃・マスカット・オブ・アレキサンドリア・ピオーネは全国1位（岡山県・農林水産省 中国四国農政局。マスカットは全国の9割ほど。岡山観光WEB）。倉敷美観地区は白壁の町並みで、くらしき川舟流しがある（岡山観光WEB）。児島は国産ジーンズ発祥の地（岡山観光WEB）。きびだんごは岡山にゆかりの昔話と結びついた菓子（岡山観光WEB、農林水産省）。岡山の言葉：「〜じゃ」（〜だ）、「でーれー」「ぼっけー」（すごい・すごく）（岡山市「岡山弁講座」、岡山県の PR、山陽新聞）
# 気をつけたこと：岡山を「何もない」といじらない。県のほうはちゃんとしている側で、ずれているのはボケの使い方だけ。昔話は題名を出さない。実在の店・会社・人・ゆるキャラの名前は出さない。「ももの生産量日本一」は言わない（もも全体の 1 位は別の県。白桃の品種で言う）
