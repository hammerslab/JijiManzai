# 中学受験。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 1：メイン「子どもより、親のほうが受験に詳しい」＋サブ（塾の予定を全部覚えている → 偏差値を小数点まで → 模試の結果で 1 上がるとケーキ 3 つ、1 下がると布団から出ない → つるかめ算が夢に出る → 塾の先生に「お母さんが受けるんですか」 → 親だけ模試を受ける → 娘に「落ち着いて」と言われる → 「ゆっくり過去問を解いてる」）
# オチ：娘に「お母さんは、ゆっくりしてて」と言われ、「だから今は、ゆっくり、過去問を解いてる」。「全然ゆっくりしてないじゃーーん！」
# 技：エスカレーション（親の熱が、予定 → 偏差値 → 一喜一憂 → 自分で解く → 自分で受ける と上がる）、天丼（布団から 3 日出ない）、たとえツッコミ（株価か・天気予報か）、スカシ（「ゆっくりしてる」と安心させてから、過去問）
# 事実：2026 年の首都圏の中学受験者数は、首都圏模試センターの推定で約 5 万 2 千人、受験率は約 18% で高い水準が続いている（東洋経済オンライン 2026 年の記事、ダイヤモンド・オンライン）。細かい数字はネタの芯にしていない
# 気をつけたこと：子どもを笑わない（娘はずっと落ち着いていて、ちゃんとしている側。成績や合否をからかわない）。受験生の親という人の集まりも笑わない（B が「応援したい気持ちは、わかる」と言う）。笑うのはボケ本人の熱の入りすぎだけ。塾・学校・模試の名前は出さない
