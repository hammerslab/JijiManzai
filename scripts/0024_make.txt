# メイク圧力。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 1：メイン「服装自由の案内に付いてくる、メイクの細かい決まり」＋サブ（服装自由 → メイクも自由。ただしナチュラル → していないように見えて、している → 口紅は唇より少しだけ明るく → 眉は自信がありすぎず、なさすぎず → すっぴんも歓迎。ただし、すっぴん風メイクで → 決まりが 30 ページ → 「自由とは、決まりを守ることです」 → 返事をしたら、自由の説明が 3 ページ増える）
# オチ：B が「メイクは、したい人がしたいだけすればいいし、しない人はしなくていい」と言い、A がそう返事を出す → 「自由について、説明を 3 ページ、お送りします」。「また増えたじゃーーん！」
# 技：天丼（「自由です。ただし」）、エスカレーション（決まりが細かく・多くなっていく）、ノリボケ（A が分度器・色見本・虫めがねで決まりを守ろうとする）、伏線回収（序盤の「ただし」→ 最後の返事にも「ただし」が付く）
# 事実：就活や式典の「服装自由」の案内で、何を着ればいいか、メイクはどこまでかが迷うと、毎年のように話題になる。公的な就職支援の場でも「就活メイク」の講座が開かれている（宮崎労働局の委託事業 2026-03）。メイクの決まりそのものの数字や調査は、確かなものが見つからなかったので、ネタの芯にしていない（あるあると言葉のずれだけ）
# 気をつけたこと：メイクをする人・しない人のどちらも否定しない（B の「したい人はすればいい、しない人もそれでいい」を正しい側に置く）。B のギャルメイクもからかわない。笑うのは、自由と言いながら細かくなっていく案内（架空の集まりの案内・仕組み）と、それを全部まじめに守ろうとするボケだけ。実在の会社・化粧品・ブランドは出さない
