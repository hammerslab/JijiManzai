# 型 1：メイン「少々・適量を量ろうとして、料理が始まらない女」＋サブ（少々をはかりにのせて 0 グラム → 100 回つまんで 50 グラム → レシピを書いた先生の指の太さを手紙で聞く → 「適量」を辞書で引くと「ちょうどいい量」、「ちょうどいい」を引くと「適量」→ 「お好みで」のために自分探しのひとり旅 → 「きつね色」を見に動物園、耳のうしろの黒まで焼く）
# オチ：相方が「料理は勘」と作ってみせる → A「私も勘でやってみる」→「勘って、何グラム？」→ B!!!「勘は量れないじゃーーん！」（天丼：何グラム）
# 技：天丼（何グラム？）、すれ違い（指 2 本でつまむ → はかりにのせる）、エスカレーション（はかり → 手紙 → 辞書 → ひとり旅 → 動物園）、見つめ合う（オチの前）
# 事実：レシピの「少々」は親指と人差し指の 2 本でつまむくらい、「ひとつまみ」は 3 本、「適量」はちょうどいい量（料理の本の一般的な目安）。台本ではグラムの目安は言わない（ボケの「0 グラム」「50 グラム」はネタ）
