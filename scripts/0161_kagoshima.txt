# 鹿児島県（都道府県シリーズ）。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 2：「鹿児島のお土産を選びすぎる女」×「覚えたての鹿児島弁」。ボケは旅行から帰ってきた外の人で、相づちの「じゃっど（そうですね）」を自分の話に自分で打ち、「わっぜ（とても）」で買いすぎ、「ずんばいあっど（たくさんあるよ）」で全部を相方に渡す（抑揚は標準語のまま）
# サブ（しょぼい → 大きい）：「じゃっど」で自分にうなずく → さつまいもを「わっぜ」買ってスーツケースがいもだけ → お茶を 20 杯飲みくらべて 21 杯目で「最初のが一番」→ 黒豚を生きたまま連れて帰ろうとする → 30 キロの桜島大根をおんぶして名前を付ける → 桜島の灰がボブにのって帰ってくる
# オチ：お土産は「ずんばいあっど」、全部あんたに → いもとお茶と大根 → 見つめ合う →「名前は、じゃっど」→ B!!!（伏線回収：大根の名前・じゃっど）
# 技：天丼（じゃっど）、伏線回収（大根に付けた名前）、エスカレーション（いも → お茶 → 黒豚 → 大根）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：鹿児島県は九州の南。さつまいも（かんしょ）の収穫量、荒茶の生産量（2 年連続）、豚の飼養頭数が全国 1 位（農林水産省「鹿児島県の農林水産業の概要」2026）。桜島大根は大きいもので直径 40〜50cm・重さ約 30kg（鹿児島県）。鹿児島弁：「じゃっど」（そうですね。相づちの言葉）、「わっぜ」（とても。「わっぜ うんまか」＝とてもおいしい）、「ずんばいあっど」（たくさんあるよ）（鹿児島県「かごしまの方言ミニ講座」リーフレット）
# 気をつけたこと：鹿児島を「何もない」といじらない。桜島は噴火の怖さや灰の被害にふれず、「灰がボブにのった」を旅の思い出として明るく扱うだけ。県のほうはちゃんとしている側で、ずれているのはボケのお土産の選び方と言葉の使い方だけ。実在の店・会社・人・商品名（かき氷の名前など）は出さない。桜島大根の「世界一」はいまは記録が更新されているので言わない
