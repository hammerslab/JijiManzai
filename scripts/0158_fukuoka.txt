# 福岡県（都道府県シリーズ）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 2：「福岡の物産展を開きたい男」×「覚えたての博多弁」。ボケは外から来た人で、人に聞くときの「〜と？」を自分のことにまで付けて何でも聞き返し、「好いとう（好き）」を何にでも言う（抑揚は標準語のまま。まねなので不自然にならない）
# サブ（しょぼい → 大きい）：辛子明太子をひと腹だけ、ライトを当てて「試食は見るだけ」→ とんこつラーメンの替え玉だけを 100 玉（スープなし）→ 博多人形が用意できず自分が人形になって 3 時間 → 屋台（夜になると出てくる）を夜にアパートの廊下へ出す → 「大家さん、好いとう」
# オチ：物産展は「大成功と？」と相方に聞く →「福岡で一番好いとうのは」→ 見つめ合う →「替え玉」→ B!!!（伏線回収：替え玉・好いとう。スカシ）
# 技：天丼（〜と？・好いとう）、伏線回収（替え玉・〜と？）、スカシ（俺じゃないのかよ）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：福岡県は九州の北。辛子明太子・とんこつラーメン・もつ鍋などの食文化（福岡県観光連盟「クロスロードふくおか」）。替え玉（麺だけのおかわり）は福岡市長浜のラーメンから広まったとされる（同）。福岡市には屋台が約 100 軒あり「日本一屋台があるまち」（福岡市「屋台Q&A」）。屋台は夕方から組み立てて営業する。博多人形は国の伝統的工芸品（クロスロードふくおか「福岡の伝統工芸品」）。博多弁：「〜と？」（〜なの？ と聞く）、「好いとう」（好き）（All About「博多弁講座」）。※佐賀（0116）の「〜ばい」「〜けん」は使っていない
# 気をつけたこと：福岡を「何もない」などといじらない。県のほうはちゃんとしている側で、ずれているのはボケの物産展と言葉の使い方だけ。実在の店・会社・人・球団・商品名（いちごの名前など）は出さない。方言は好きでまねしている向き（からかわない）
