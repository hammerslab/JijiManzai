# 群馬県（都道府県シリーズ）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 2：「群馬に移住したくて、相方を誘いすぎる男」×「覚えたての群馬の言葉」。ボケは外から来た人で、誘う「〜べえ（〜しよう）」で相方を引っ越しに誘い続け、推量の「〜だんべえ（〜だろう）」を自分の気持ちに付ける（抑揚は標準語のまま。まねなので不自然にならない）
# サブ（しょぼい → 大きい）：何でも「べえ」で誘う → 焼きまんじゅうのみそだれを何にでも塗る → こんにゃくいもを焼きいもにしようとして農家の人まで誘う → 草津の湯畑に種をまく → 高崎のだるまに「移住できますように」
# オチ：移住は？ → 見つめ合う → だるまだけ群馬に送った、「先に行ってるべえ」と言っていた → B!!!（伏線回収：誘う「べえ」と移住）
# 技：天丼（べえで誘う）、伏線回収（べえ・移住）、たとえツッコミ、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：群馬県のこんにゃくいもは全国の収穫量の 9 割以上（令和 6 年産 97%。群馬県の資料、農水省の都道府県の概要）。キャベツなども収穫量全国 1 位（関東農政局）。草津温泉は自然に湧き出る湯の量が日本一とされ、町の真ん中に湯畑があり、湯もみ（長い板でお湯を混ぜて冷ます）が見られる（るるぶ、草津温泉の紹介記事）。焼きまんじゅうは串に刺したまんじゅうに甘いみそだれを塗って焼く郷土料理（農水省「うちの郷土料理」）。高崎はだるまの産地で、願いをかけるとき片方の目を、かなったらもう片方を塗る（高崎の観光協会の資料、旅の記事）。富岡製糸場は世界遺産。群馬の方言「べえ」は意志・勧誘（〜しよう）、「だんべえ」は推量（〜だろう）、「なっから」は「とても」（群馬弁の記事。主な出どころは杉村孝夫『講座方言学5 関東地方の方言』）
# 気をつけたこと：群馬を「何もない」「秘境」などといじらない。県のほうはちゃんとしている側で、ずれているのはボケの使い方だけ。方言は好きでまねしている向き（からかわない）。こんにゃくいもを生で食べることはすすめない（農家の人に止められる）。実在の店・会社・人の名前は出さない。だるまの順位の数字は出さない
