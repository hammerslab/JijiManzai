# ビール系の酒税一本化。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「税の話を聞いて、お酒売り場で経済評論家になる」＋サブ（腕組み「大きなうねり」→ 隣のお客さんに解説 → 9 円を 10 年積み立て → 需要と供給 → 店長に見通しを聞く → 駆け込み → ひとりで中継）
# オチ：評論家としての結論は「ビールは安くなった。発泡酒は高くなった。以上です」＝冒頭でツッコミが説明したこと（伏線回収）
# 技：伏線回収（冒頭の説明 → 結論）、天丼（「動向を、見守る」）、スカシ（見つめ合う →「以上です」）、エスカレーション（腕組み → 解説 → 計算 → 店長 → 中継）
# 事実：2026-10-01 の酒税改正で、ビール・発泡酒・新ジャンルの酒税が 350ml あたり 54.25 円に一本化。ビールは約 9 円（9.10 円）の減税、麦芽比率 25% 未満の発泡酒と新ジャンルは約 7 円（7.26 円）の増税。2020・2023・2026 年の 3 段階の見直しの最後。増税前に発泡酒の駆け込み需要も報じられた
#   出典：秋田魁新報「酒税改正でビール値下げ開始」（2026-10-01）、熊本日日新聞（2026-10）、KSB 瀬戸内海放送（2026-09）
# 気をつけたこと：商品名・会社名・店名は出さない。税の良し悪しは言わず、ボケの評論家ぶりのずれだけで笑う。お酒を飲む量の話にしない（「1 本あたり」の計算だけにして、買いだめ・飲みすぎは出さない）。店長・お客さんは「ちゃんとしている」側
