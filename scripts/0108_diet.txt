# ダイエット。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 1：メイン「ダイエットを『明日から』と言い続けて、食べていい理屈ばかり作る女」＋サブ（「明日から」が 3 年 → 腹八分目を「8 分おきに食べる」と勘違い → 「サービスです」はタダだから 0 円で 0 キロカロリー → 歩数計を扇風機につけて 1 万歩、ごほうびのパフェ → カロリー計算のアプリに「ふわふわ」と入れる → 世界のどこかで毎日だれかの誕生日だから、ケーキは毎日お祝い）
# オチ：相方が「今日から一緒に歩こう」と誘う → A「記念にケーキ」→「毎日、あなたの誕生日ってことにした」→ B!!!「一年で 365 歳になるじゃーーん！」（伏線回収：誕生日の理屈）
# 技：言い間違い・勘違い（腹八分目）、エスカレーション（理屈が大きくなる）、天丼（「明日から」）、伏線回収（誕生日の理屈 → 相方の誕生日）、見つめ合う（オチの前）
# 気をつけたこと：体型や体重をからかわない（2 人の見た目にも、体重の数字にもふれない）。食事を抜く・無理に減らすなど、無理なダイエットをすすめない（ずれているのはボケの食べていい理屈だけ。ツッコミは「無理しないで少しずつ」の側）。
#       有名な「カロリーゼロ理論」のネタ（ドーナツの穴・揚げ物の熱でカロリーが飛ぶ など）は使わず、別の理屈にした。食べ物の店や商品の名前は出さない。半額シール（0008）・昨日の私（0015）とはかぶらないようにした
