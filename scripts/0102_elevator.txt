# エレベーター。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「「閉」ボタンを押す派か待つ派か、乗ってきた人みんなに聞いて回る男」＋サブ（知らない人に聞く → 考えてるうちに 12 階まで行って「待つ派です」→ 答えを聞くまで「開」を押してエレベーターが動かない → 押す派 50・待つ派 50 で、1 日 300 往復 → 「階段派」の人を追って階段で息切れ → 管理人に案内係とまちがわれ、閉めるかどうかを毎回お客さんに聞く）
# オチ：自分は「聞く派」。相方が「もういいよ」で閉めようとすると「開」を押して止め、最後に客席に「皆さんは、押す派ですか、待つ派ですか」→ B!!!「お客さんに聞くな！」
# 技：天丼（押す派ですか、待つ派ですか）、伏線回収（「開」を押す → 漫才の締めを開けたままにする）、スカシ（階段派が一番健康）、ノリボケ（案内係）、見つめ合う（オチの前）
# 気をつけたこと：0039 タワマン（エレベーター待ちで景色を見ない）とかぶらないよう、待ち時間ではなく「閉」ボタンの派閥に絞った。乗ってくる人は笑いものにしない（おかしいのはボケの聞き方）。いたずらでボタンを全部押す、などはしない
