# 香川県（都道府県シリーズ）。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 2：「香川の旅の思い出話を語りたい女」×「覚えたての讃岐弁」。ボケは旅行から帰ってきた外の人で、覚えたての「〜まい（〜しなさい）」「〜けん（〜だから）」「まんでがん（全部）」を取り違えたり使いすぎたりする（抑揚は標準語のまま）
# サブ（しょぼい → 大きい）：「食べまい」を「食べちゃだめ」と思って、うどんを 2 時間見つめる → 「まんでがん」でトッピングを全部のせ → 小豆島のオリーブのオイルでうどんをゆでて天ぷらに → 丸亀うちわでうどんを冷ましたら、ざるうどんが飛んでいく → こんぴらさんの石段 785 段を 1 段ずつ写真に撮る
# オチ：2 時間見つめたうどんを、おみやげにもらって、まだ冷蔵庫で見つめている → 見つめ合う → B!!!「早く、食べまい！」（伏線回収：食べまい。ツッコミが讃岐弁を正しく使ってしまう）
# 技：伏線回収（食べまい）、天丼（うどんを見つめる）、ノリツッコミ（うちわ）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：香川県は四国の北東で、瀬戸内海に面する。うどんの生産量は日本一（香川県の資料）。オリーブは香川県の県花・県木で、生産量は全国一。日本でオリーブの栽培がはじめてうまくいったのが小豆島（香川県の資料）。丸亀うちわは国の伝統的工芸品で、うちわの生産量は日本一（国内の約 9 割。香川県観光協会の資料、香川県の資料）。金刀比羅宮（こんぴらさん）は、参道の入口から御本宮まで石段が 785 段（旅行情報の各サイト）。讃岐弁：「〜まい」＝〜しなさい（「食べまい」＝食べなさい）、「〜けん」＝〜だから、「まんでがん」＝全部、あるだけ全部（Wikipedia「讃岐弁」）。（割合の数字は台本に出さない）
# 気をつけたこと：香川を「うどんしかない」「小さい県」といじらない（面積の話はしない）。県のほうはちゃんとしている側で、ずれているのはボケの取り違えと思い出話だけ。方言は好きでまねしている向き（からかわない）。こんぴらさんは観光の石段としてだけ出し、からかわない。「へらこい」など県民性の言葉は使わない。実在のうどん店・会社・ゆるキャラの名前は出さない
