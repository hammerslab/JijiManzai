# 魚に気をつかう男

- お題：釣り
- コンビ：男性　ボケ・アフロ／ツッコミ・モヒカン
- 長さ：2分50秒（VOICEVOX の声で作ったとき）

記号：〔間〕＝少し黙る、【叩く】【強く叩く】【思いきり叩く】＝手刀でツッコむ（効果音つき。頭の「ワッーーツ！」は自動で付く）、〈〉＝そこだけ声を変える

**2 人**　どうもー、よろしくお願いしますー！

**ツッコミ・モヒカン**　釣りって、いいよな。海や川で、糸をたらして、魚がえさに食いつくのを、のんびり待つ。休みの日の、楽しみにしてる人も、多いんだよ。

**ボケ・アフロ**　〔間〕俺も、始めた。

**ツッコミ・モヒカン**　お、いいね。釣れたか？

**ボケ・アフロ**　〔間〕一匹も、釣ってない。

**ツッコミ・モヒカン**　まあ、最初は、そんなもんだよ。

**ボケ・アフロ**　〔間〕釣らないように、してる。

**ツッコミ・モヒカン**　なんでだよ。釣りに、行ってるんだろ。

**ボケ・アフロ**　魚に、悪いから。

**ツッコミ・モヒカン**　気をつかうとこ、そこか。

**ボケ・アフロ**　海に着いたら、まず、あいさつする。

**ツッコミ・モヒカン**　あいさつ？

**ボケ・アフロ**　〔間〕「おじゃまします」

**ツッコミ・モヒカン**　人の家か！ 海は、そんなに、かしこまらなくていいんだよ！

**ボケ・アフロ**　〔間〕水面を、3回、ノックしてから。

**ツッコミ・モヒカン**　【叩く】ワッーーツ！ 水面は、ノックできないだろ！ ちゃぷちゃぷ、いってるだけじゃないか！

**ボケ・アフロ**　えさを、針に、つける。

**ツッコミ・モヒカン**　そうそう、ここからが、本番だ。

**ボケ・アフロ**　〔間〕針が、とがってて、危ない。

**ツッコミ・モヒカン**　まあ、針だからな。

**ボケ・アフロ**　〔間〕だから、針を、外した。

**ツッコミ・モヒカン**　【叩く】ワッーーツ！ 外すな！ それじゃ、魚が、かからないだろ！

**ボケ・アフロ**　えさだけ、海に、投げた。

**ツッコミ・モヒカン**　ただの、えさやりじゃないか。

**ボケ・アフロ**　〔間〕魚が、食べてくれた。

**ツッコミ・モヒカン**　そりゃ、食べるよ。針がないんだから。

**ボケ・アフロ**　〔間〕「おいしかったですか」って、聞いた。

**ツッコミ・モヒカン**　返事は、ないだろ。

**ボケ・アフロ**　〔間〕泡が、ぷくって、出た。

**ツッコミ・モヒカン**　〔間〕……それは、たぶん、違うと思うぞ。

**ボケ・アフロ**　〔間〕「おかわり」って、意味だと思って、

**ツッコミ・モヒカン**　思うな。

**ボケ・アフロ**　〔間〕1袋、全部、あげた。

**ツッコミ・モヒカン**　【叩く】ワッーーツ！ 全部あげるな！ お前、魚を、太らせに行ってるだけだろ！

**ボケ・アフロ**　次の週も、行った。

**ツッコミ・モヒカン**　こりないな。

**ボケ・アフロ**　〔間〕魚が、集まって、待ってた。

**ツッコミ・モヒカン**　覚えられてるじゃないか！ えさを、くれる人だって！

**ボケ・アフロ**　隣で、釣ってた、おじいさんが、言った。

**ツッコミ・モヒカン**　うん。

**ボケ・アフロ**　〔間〕「兄ちゃんの前だけ、魚が、渋滞しとるのう」〈おじいさんの声〉

**ツッコミ・モヒカン**　魚の、渋滞！

**ボケ・アフロ**　だから、その場所を、おじいさんに、ゆずった。

**ツッコミ・モヒカン**　お、えらいじゃないか。

**ボケ・アフロ**　〔間〕おじいさん、大漁。

**ツッコミ・モヒカン**　よかったな。おじいさん、うまいんだな。

**ボケ・アフロ**　〔間〕お礼に、魚を、1匹、もらった。

**ツッコミ・モヒカン**　【強く叩く】ワッーーツ！ 釣ったんじゃなくて、もらってるだけじゃないか！ お前の釣果、おすそわけだけだろ！

**ボケ・アフロ**　初めて、魚を、持って帰った。

**ツッコミ・モヒカン**　まあ、持って帰れて、よかったな。焼いたのか？

**ボケ・アフロ**　〔間〕水そうで、飼ってる。

**ツッコミ・モヒカン**　飼ってるのかよ！

**ボケ・アフロ**　〔間〕名前は、「おじいさん」。

**ツッコミ・モヒカン**　くれた人の、名前を、つけるな！ ややこしいだろ！

**ボケ・アフロ**　毎週、海に、行ってる。

**ツッコミ・モヒカン**　今度こそ、釣るのか。

**ボケ・アフロ**　〔間〕おじいさんの、家族に、近況を、報告しに。

**ツッコミ・モヒカン**　【強く叩く】ワッーーツ！ 魚の家族に、報告するな！ 「元気に、泳いでます」って、言いに行ってるのかよ！ もう、釣りじゃないだろ！

**ツッコミ・モヒカン**　だいたいお前、釣りの日の、晩ごはんは、どうしてるんだよ。

**ボケ・アフロ**　帰りに、

**ツッコミ・モヒカン**　うん。

**ボケ・アフロ**　〔間〕スーパーで、お刺身を、買う。

**ツッコミ・モヒカン**　【思いきり叩く】ワッーーツ！ 食べるのかよ！ さっきまでの、気づかいは、どこに行ったんだよ！ もういいよ！

**2 人**　どうも、ありがとうございましたー！
