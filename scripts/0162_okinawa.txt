# 沖縄県（都道府県シリーズ）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 2：「沖縄の観光ガイドになりたい男」×「覚えたての沖縄の語尾」。ボケは外から来た人で、のんびりした語尾「〜さー」「〜ねー」を両方付けて案内が進まず、「なんくるないさー」を言い訳に使う（抑揚は標準語のまま。まねなので不自然にならない）
# サブ（しょぼい → 大きい）：「めんそーれ」でガイドを始める →「右手に見えますのは、ねー、海さー」→ 沖縄そばを「そばじゃないさー」→ ゴーヤーを生でかじってずっと苦い顔 → シーサーのかわりに屋根にのぼって口をあける → 海がきれいすぎてガイドが先に泳ぎ、気づいたら夕方
# オチ：決めぜりふ「なんくるないさー」→ B が本来は「まくとぅそーけー、なんくるないさー」（まじめにがんばれば、なんとかなる）と教える →「じゃあ、まじめにがんばるさー」→ 見つめ合う →「明日から、ねー」→ B!!!（伏線回収：のんびりの「ねー」）
# 技：天丼（〜さー・〜ねー）、伏線回収（ねー）、ノリボケ（シーサーのまね）、たとえツッコミ、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：沖縄県は日本の一番南の県。にがうり（ゴーヤー）・パインアップル・さとうきび・マンゴーなどの収穫量が全国 1 位（農林水産省「沖縄県の農林水産業の概要」2026）。沖縄そばは小麦粉の麺で、そば粉を使わないが、1978 年に「本場沖縄そば」として表示が認められた（沖縄県生麺協同組合）。シーサーは屋根や門の上から魔物を追い払うとされる（琉球新報）。「めんそーれ」（いらっしゃい・ようこそ）（All About）。「なんくるないさ」はもとは「まくとぅそーけー、なんくるないさ」で、「正しいことを努力してやれば、きっとうまくいく」という意味（琉球新報のコラム、沖縄語普及協議会の解説）。語尾「〜さー」「〜ねー」は利用者の指定（2026-11-16「沖縄なら語尾が『ね～』みたいな」）と、「なんくるないさー」「なんでかね〜」の言い方から
# 気をつけたこと：基地・戦争・政治にはふれない（名物・海・言葉の楽しい回）。首里城も出さない。沖縄を「のんびり」「てーげー」と県民性の悪口にしない（のんびりしすぎているのはボケだけで、B が「まじめにがんばれば」の本来の意味を教える）。実在の店・会社・人・水族館・ドラマや歌の題名は出さない
