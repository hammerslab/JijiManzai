# 型 1：メイン「ニュースのコメント欄」＋サブ（記事が出る前に書く → 「現場の近くに住んでいますが」＝南極 → 「元関係者ですが」＝ウサギの飼育係 → 3000字で自分に返信 → 「そう思わない」を押したのは自分 → 天気予報に疑問 → この漫才のコメント）
# オチ：この漫才にも「現場で見ていましたが、ツッコミの人、叩きすぎだと思います」と書いてある → 現場にいるのも、叩かれているのも本人
# 技：天丼（「私は前から、こうなると思っていました」「近くに住んでいますが」）、たとえツッコミ（予言者か・連載か・鳥か）、伏線回収（現場を見たような書き方 → 本当に現場にいる）、見つめ合う
# 事実：ニュースサイトの記事の下のコメント欄には、記事が出てすぐ、長いコメントがたくさんつく（時期を問わないあるある。数字・調査は使わない）
