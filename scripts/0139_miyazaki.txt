# 宮崎県（都道府県シリーズ）。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 2：「宮崎に移住したい女」×「覚えたての宮崎弁」。ボケは外の人で、覚えた宮崎の言葉（てげ＝とても、てげてげ＝適当、じゃかいよ＝ほんとそれ、〜っちゃ）を取り違えたり、うなずきすぎたりする（抑揚は標準語のまま）
# サブ（しょぼい → 大きい）：「てげてげ楽しみ」（とても、のつもりで「適当」）→ 何にでも「じゃかいよ」でチキン南蛮を 5 皿 → 日向夏の白いところを全部取って小さくなる → 完熟マンゴーが落ちるのを口をあけて待つ → 高千穂峡の貸しボートに住めるか確かめる
# オチ：移住の相談で「来月からでいいですか」に「じゃかいよ」→「お友だちも、どうですか」にも「じゃかいよ」→ 見つめ合う → 相方も移住することに → B!!!、でも最後は B も「じゃかいよ」（伏線回収：じゃかいよ）
# 技：言い間違い・勘違い（てげ／てげてげ）、天丼（じゃかいよ）、伏線回収（じゃかいよ）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：宮崎県は九州の南東。日ざしが多く、快晴の日数も全国上位（宮崎県、農林水産省）。きゅうりの収穫量・出荷量は全国1位（令和6年産。宮崎県「宮崎の1番」）。チキン南蛮は延岡市が発祥（農林水産省「うちの郷土料理」、宮崎県）。日向夏は宮崎原産の柑橘で、白い内皮もいっしょに食べる（宮崎県）。完熟マンゴーは木の上で熟して自然に落ちたものをネットで受け止める（宮崎県）。高千穂峡には真名井の滝があり、貸しボートで見上げられる（高千穂町観光協会）。宮崎の言葉：「てげ」（とても）、「てげてげ」（適当）、「じゃかいよ」（強く同意するとき）（宮崎市「宮崎弁講座」、九州農政局 宮崎県拠点）、「〜っちゃ」（〜だよ。論文の用例）
# 気をつけたこと：宮崎を「何もない」「田舎」といじらない。「てげてげ」を県民性の悪口にしない（ボケの取り違えだけ）。県のほうはちゃんとしている側。実在の店・会社・人・ブランド名（マンゴーの名前など）は出さない。移住はすすめる向きで、からかわない
