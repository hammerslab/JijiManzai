# 回転寿司。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「もう一周待てば、もっといいのが来ると思って、何も取れない男」＋サブ（マグロを 12 周見送る → タッチパネルで頼んだ自分の皿まで見送る → 金色の皿を 3 周拝む → 待ちきれず、レーンと同じ速さで店の中を歩いて、自分も回る → 子どもに「あれ、なんのネタ？」→ お会計は 0 皿）
# オチ：「今日はこのへんで」と締めようとすると「もう一周、見てから決める」→ 漫才の頭のあいさつからやり直す → B!!!「漫才を、もう一周するな！」（天丼：もう一周）
# 技：天丼（「もう一周」「見送った」）、すれ違い気味の言葉遊び（ネタ＝寿司の具と漫才のネタ）、たとえツッコミ（神社か）、スカシ（お会計 0 皿）、見つめ合う（オチの前）
# 気をつけたこと：店の名前は出さない。レーンの寿司にさわる・いたずらするなど、お店の迷惑になることはさせない（ボケは見送るだけ、歩くのも店の中の通路）。お店の人や子どもをけなさない
