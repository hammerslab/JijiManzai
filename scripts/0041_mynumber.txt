# マイナンバーカード。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「一枚で済むはずが、暗証番号を思い出すためのメモが増えていく」＋サブ（財布は軽く、メモ帳が重い → 4 つとも違う番号 → コンビニで 2 回間違える → 引き出しのメモ 47 枚 → メモをカードと一緒に…（ツッコミが止める）→ メモのメモ → 窓口で再設定）
# オチ：窓口で新しい番号にしたが、忘れないように相方に覚えてもらった → 「俺がメモ帳か！」
# 技：エスカレーション（メモ → メモ 47 枚 → メモのメモ → 相方がメモ帳）、ノリボケ（カードの裏 → おでこ）、伏線回収（「一枚で済む」→ 紙が増える）、スカシ（見つめ合う →「お前に、覚えてもらった」）
# 事実：暗証番号は 4 種類。署名用電子証明書（英数字 6〜16 桁、英字は大文字）、利用者証明用電子証明書・住民基本台帳用・券面事項入力補助用（数字 4 桁、同じ番号にしてよい）。利用者証明用は 3 回続けて間違えるとロック。忘れたら役所の窓口などで再設定できる
#   出典：板橋区・文京区・仙台市などの自治体の案内、国税庁 e-Tax の FAQ（2026-10 に確認）
# 気をつけたこと：制度の良し悪しを言わない（便利な仕組みとして扱い、おかしいのはボケだけ）。暗証番号の悪い扱い（メモをカードと一緒に持つ、カードに書く、人に教える、人前で言う）は、出たその場でツッコミが止め、正しいやり方（窓口で再設定・自分で覚える）を言う。コンビニの店員さんは「ちゃんとしている」側
