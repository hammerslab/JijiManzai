# 埼玉県（都道府県シリーズの試し）。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 2：「埼玉県の観光大使になりたい女」×「埼玉弁を話したいのに、埼玉はほぼ標準語」。ボケは語尾がほしくて、自分で作った語尾「〜さいたま」を何にでも付ける
# サブ（しょぼい → 大きい）：語尾「〜さいたま」を作る → 深谷ねぎをマフラーにする → 草加せんべいの音で相方を起こす → 「小江戸」の川越で小さい江戸を探す → 盆栽を 10 年かけて自分の髪型（ボブ）にする → 海がないので川の多さを数える
# オチ：観光大使のあいさつを「全部、埼玉弁で言える」→ ふつうにしゃべる →「今のが、埼玉弁」→ 見つめ合う → B!!!（伏線回収：埼玉はほぼ標準語）
# 技：天丼（〜さいたま）、伏線回収（ほぼ標準語）、ノリツッコミ（ねぎのマフラー）、見つめ合う（オチの前）
# 事実（2026-11-16 時点）：埼玉県は東京のとなり。深谷ねぎ（ねぎは県内の野菜でいちばん作付面積が大きい）、草加せんべい、蔵造りの町並みの川越（「小江戸」）、大宮の盆栽などが知られる。海はないが川が多い（河川の面積の割合は全国でも上位）。埼玉の言葉は、標準語とあまり変わらないと思われていることが多い（農水省、埼玉県の資料、論文）。（順位の数字は台本に出さない）
# 気をつけたこと：埼玉を「何もない」「ダサい」といじらない。映画やよその作品のネタは使わない。県のほうはちゃんとしている側で、ずれているのはボケの語尾と使い方だけ。実在の店・会社・人の名前は出さない。川で泳ぐことはすすめない
