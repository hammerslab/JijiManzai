# 広島県（都道府県シリーズ）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 2：「広島のお好み焼きをきわめたい男」×「覚えたての広島弁」。ボケは外から来た人で、「じゃけえ（だから）」をあいさつに付けて続きを言わず、「たいぎい（めんどくさい）」をほめ言葉だと思って使い、直されると「はぶてる（すねる）」（抑揚は標準語のまま。まねなので不自然にならない）
# サブ（しょぼい → 大きい）：あいさつに「じゃけえ」→ お好み焼き屋さんで「たいぎい味」とほめる → もみじまんじゅうを作ろうと山でもみじを拾う → かきを殻ごと入れる → 熊野の筆でソースを塗って「広島」と書く → 名物を全部重ねて高さ 1 メートル（筆まで）
# オチ：きわめた一枚は、何も足していない、ふつうの広島のお好み焼き → 見つめ合う → B!!!（伏線回収：重ねて焼く。広島のお好み焼きは最初から完成している、で県をほめて終わる）
# 技：天丼（重ねる）、伏線回収（何も足さない）、言い間違い・勘違い（たいぎい）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：広島県は中国地方。宮島（海に立つ大きな鳥居）、宮島の名物のもみじまんじゅう。かきの生産量は日本一（広島県の「かき生産出荷指針」など）、レモンの生産量も日本一（広島県の農林水産業の資料。国産の 5 割以上）。熊野町は筆づくりの町で、筆の生産量は日本一（全国の 8 割以上。広島県・内閣府の資料）。広島のお好み焼きは生地・キャベツ・そばなどを重ねて焼く。広島弁の「じゃけえ」は「だから」、「たいぎい」は「おっくう・めんどくさい」、「はぶてる」は「すねる・ふくれる」（All About の方言クイズ、マイナビニュース、広島大学の論文）
# 気をつけたこと：原爆・戦争にはふれない。宮島の鳥居（神社）は紹介で名前を出すだけで、ネタにしない。もみじの形のお菓子は一般の名前「もみじまんじゅう」で、店や会社の名前は出さない。プロ野球の球団名は出さない。県のほうはちゃんとしている側で、最後は広島のお好み焼きをほめて終わる
