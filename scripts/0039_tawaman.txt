# タワマン（タワーマンション）。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 1：メイン「タワマンの 45 階に住んだのに、景色を見たことがない」＋サブ（朝のエレベーター → 乗ったら後ろを向く → 忘れ物 → 出前のラーメン → エレベーターの研究 → やっと見た窓は雲の中 → 引っ越し）
# オチ：景色を見るために、向かいの低いマンションの 2 階に引っ越した。「前のタワマンが、よく見える」→ 景色って、タワマンを見る側だった
# 技：天丼（「乗れない」の繰り返し・45 階）、エスカレーション（朝 → 半日 → 研究 → 引っ越し）、スカシ（「たぶん。」）、伏線回収（景色を見たことがない → 外から見る）
# 事実：タワマン＝タワーマンション。だいたい 20 階建て以上の高いマンション（決まった定義はない）。朝の出勤時にエレベーターが混む、はよく言われるあるある。事実の数字はネタの芯にしていない
# 気をつけたこと：住む人をからかわない。ほかの住人・配達の人は「ちゃんとしている」側に置き、おかしいのはボケのずれだけ。実在のマンション名・地名は出さない
