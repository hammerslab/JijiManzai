# 秋田県（都道府県シリーズ）。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 2：「秋田に移住したい女」×「覚えたての秋田弁『〜っこ』」。ボケは、小さいもの・親しみのあるものに付ける「っこ」を、何にでも、大きいものにまで付ける（抑揚は標準語のまま）
# サブ（しょぼい → 大きい）：お茶っこ・飴っこ → 請求書っこ → きりたんぽを杉の棒がないのでリコーダーに巻く → 竿燈っこ（ストローにポチ袋）→ なまはげを「なまはげっこ」と呼んで頭をなでる → 日本一深い田沢湖を「田沢湖っこ」
# オチ：移住の荷物は「荷物っこ、少しだけ」→ 竿燈 1 本、12 メートルの → 見つめ合う → B!!!（伏線回収：「っこ」は小さいもの、竿燈っこ）
# 技：天丼（っこ）、伏線回収（竿燈っこ → 本物の竿燈）、たとえツッコミ、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：秋田県は東北の日本海側。きりたんぽ、稲庭うどん、男鹿のなまはげ（大みそかの行事。ユネスコ無形文化遺産）、角館の武家屋敷、秋田犬などが知られる（観光サイト各種）。竿燈まつりは長い竿に提灯をつけて手のひら・額・腰などで支える。いちばん大きい「大若」は長さ 12m・重さ約 50kg・提灯 46 個（JR 東日本の記事、観光サイト）。田沢湖は最大水深 423.4m で日本一深い湖（仙北市、東北観光推進機構）。方言「〜っこ」は名詞に付けて、小さいもの・親しみのあるものを表す（例：お茶っこ、犬っこ）。「んだ」は「そうだよ・はい」（ウィキペディア「秋田弁」）
# 気をつけたこと：秋田を「何もない」「寒いだけ」といじらない。なまはげは行事として茶化さず、ボケがかわいがりすぎるだけ。方言は好きでまねしている向き。実在の店・会社・人の名前は出さない。秋田犬は犬種の名前として出すだけ
