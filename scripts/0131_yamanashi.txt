# 山梨県（都道府県シリーズ）。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 2：「山梨県民になりきりたいのに、なりきれない女」×「覚えたての甲州弁」。ボケは外から来た人で、推量の「〜ずら（〜だろう）」を自分のことに付け、「〜し（〜しなさいよ）」で命令ばかりする。甲州弁でも「じゃん」を使うと知って、ギャルの相方を山梨の人だと思う
# サブ（しょぼい → 大きい）：相方の「じゃん」を甲州弁だと思う → 自分のことに「ずら」→ 日本一のくだものを全部「むけし」→ 逆さ富士を見るため逆立ち（地元の人に「しちょ」と止められる）→ ほうとうを「伝家のほうとう」に
# オチ：県民としてのあいさつで命令ばかり、でも「逆立ちは、しちょ」だけ合っている → 見つめ合う →「私は、山梨県民、ずら」→ B!!!（伏線回収：ずら・しちょ）
# 技：天丼（ずら・〜し）、言い間違い（伝家の宝刀 → ほうとう）、伏線回収（しちょ・ずら）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：山梨県はもも・ぶどう・すももの収穫量が全国 1 位（令和 6 年産。農水省の都道府県の概要、山梨県の日本一のページ）。ミネラルウォーターの生産量も日本一（山梨県）。ほうとうは山梨の郷土料理の代表（山梨県の資料）。富士山は山梨と静岡にまたがり、富士五湖では湖に映る「逆さ富士」が見られる。甲州弁の「ずら」は推量（〜だろう）、「〜し」は命令のあとに付けてやわらかくする（勉強しろし＝勉強しなさいよ）、「〜ちょ」は「〜するな」（無理をしちょ）、「じゃん」も使う（〜じゃんけ＝〜じゃないか）（山梨県の甲州方言番付表、山梨県立図書館の方言の調べ方、甲州弁の記事）
# 気をつけたこと：山梨を「何もない」といじらない。富士山をどちらの県のものかで争わない。県のほうはちゃんとしている側で、ずれているのはボケの使い方だけ。方言は好きでまねしている向き（からかわない）。逆立ちは地元の人に止められて終わる（すすめない）。実在の店・会社・人の名前、お菓子の商品名は出さない
