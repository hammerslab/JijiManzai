# 和歌山県（都道府県シリーズ）。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 2：「和歌山の旅番組のリポーターになりたい女」×「覚えたての和歌山弁」。ボケは外の人で、覚えたての語尾（〜ら＝〜しよう、〜さかい＝〜だから）を場面に合わない使い方をする（抑揚は標準語のまま。まねなので不自然にならない）
# サブ（しょぼい → 大きい）：何にでも「〜ら」を付ける → 「〜さかい」で文が止まる → 梅干しの食レポで顔が梅干しになってしゃべれない → 湯浅の醤油を香水にする → 熊野古道の入口で噛んでやり直し 10 回 → 那智の滝の音で声が届かないので、フリップを 1 メートルに 1 枚
# オチ：番組の締めに「つれもていこら（いっしょに行こう）」→ 使い方は合っている → ついてきたのは町じゅうのねこ → 見つめ合う → B!!!（伏線回収：醤油の香水）
# 技：天丼（〜ら）、スカシ（「さかい」で止まる）、伏線回収（醤油の香水 → ねこ）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：和歌山県は近畿の南部。令和6年産で、うめ・みかん・かきの収穫量が全国1位（農林水産省 近畿農政局「令和6年産 うめ・みかん」、和歌山県の果樹の資料）。湯浅町は「醤油醸造の発祥の地 紀州湯浅」として日本遺産（2017年。和歌山県・湯浅町）。熊野古道は世界遺産「紀伊山地の霊場と参詣道」の一部。那智の滝は落差133mで、一段の滝として日本一（JAL・ANA の旅の案内）。和歌山の言葉：「〜ら」は「〜しよう」（「行こら」。県民の友の知事のことばの「いこらよ」、和歌山県ふるさとアーカイブの「いこららよー」）、「つれもていこら」（いっしょに行こう。和歌山市の協働の取り組みの名前）、「〜さかい」は「〜だから」（和歌山県ふるさとアーカイブ「和歌山の方言」の会話文）
# 気をつけたこと：和歌山を「何もない」といじらない。県のほうはちゃんとしている側で、ずれているのはボケの使い方だけ。動物の施設・実在の店・会社・人の名前は出さない。那智の滝は観光地として出し、からかわない
