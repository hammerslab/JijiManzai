# 昭和・平成（レトロブーム）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「レトロ」＋サブ（ガラケーを開け閉めするだけ → 16 和音 → フィルムカメラをスマホで撮る → レンズのキャップ → 喫茶店のマスター「ずっと現役じゃ」→ レトロの範囲がどんどん最近になる → さっきのツッコミがエモい → 未来のレトロに今日の牛乳 → 叩くツッコミもレトロ）
# オチ：30 年後の若い人は「叩くツッコミ、レトロでエモい」と言うから、今のうちにたくさん叩いておいて → 見つめ合う → 自分から頼むな！ うちのツッコミは、ずっと現役だよ！（喫茶店のマスターの「ずっと現役」を回収）
# 技：伏線回収（マスターの「50 年、ずっとこれじゃ」→ 最後の「ずっと現役」）、畳み掛け（去年のカレンダー → 先月のチラシ → 今朝の天気予報）、天丼（さっきのツッコミを懐かしむ）、スカシの間（見つめ合う）
# 事実：昭和や平成の物を「レトロ」として楽しむブームが続き、若い世代ではガラケー・プリクラ・フィルムカメラなどの「平成レトロ」が新鮮に受けている。2026 年上半期の Z 世代のトレンド調査でも平成レトロの加速が目立った（BELLOWL のプレスリリース 2026、@DIME、NTT 東日本 BizDrive）
# 気をつけたこと：どの世代も笑いものにしない。懐かしむ人・新鮮に感じる若い人・ずっと続けている喫茶店は、みんな「ちゃんとしている」側。ずれているのは、レトロの範囲がどんどん最近になるボケだけ。実在の店・商品名は出さない
