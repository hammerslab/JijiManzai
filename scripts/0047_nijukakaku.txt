# 二重価格。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 1：メイン「二重価格」＋サブ（観光客の格好 → 窓口で高いほうを払う → 毎週食べてる名物を初めて食べたふり → 自分の家への道を聞く → 実家に観光客価格で泊まる → 相方の「ようこそ」にお金を払う）
# オチ：観光客は「ようこそ」と言ってもらえるのがうらやましい → B がやさしく「ようこそ」と言ってあげる → A が「観光客で、1枚」→ 叩いて「あたしの『ようこそ』に、お金払わないで！」
# 技：勘違い（地元なのに、わざわざ高いほうを払う）、天丼（「観光客で、1枚」）、伏線回収（ようこそ → 観光客で 1 枚）、見つめ合う（オチの前）
# 事実：二重価格＝観光地などで、地元の人と、外から来た人とで値段を分けること。2026 年 3 月に国土交通相が公的な観光施設向けの指針を作ると表明し、4/27 に観光庁の有識者検討会が初会合を開いた（熊本日日新聞 2026-03・秋田魁新報 2026-04-27、いずれも共同通信配信）
# 気をつけたこと：外国の人・特定の国の話をしない（「観光客」「外から来た人」とだけ言う）。窓口の人・お店の人・お隣さん・お母さんは親切でちゃんとしている側に置き、おかしいのはボケだけ。
#   制度の良し悪しは言わない。地名・施設名は出さない（「地元のお城」）。お店も責めない
