# 岩手県（都道府県シリーズ）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 2：「岩手でわんこそばの係（お椀にそばを入れるお店の人）になりたい男」×「覚えたての盛岡弁」。ボケは外から来た人で、覚えたての「〜なはん（〜ね）」を何にでも付け、「おでんせ（おいでください）」を帰る人にまで言う（抑揚は標準語のまま）
# サブ（しょぼい → 大きい）：帰るお客さんにも「おでんせ」→ 家でお母さんのみそ汁に「はい、じゃんじゃん」（ふたを知らない）→ 南部鉄器の鉄瓶でお茶もわんこ、自分の腕が先に終わる → 本州一広い県じゅうに出前でわんこ、1 杯 2 時間
# オチ：相方で練習 →「おなかいっぱい、ふたをする」→ 見つめ合う →「ふたの上に、のせた」→ B!!!（伏線回収：ふたは終わりの合図）
# 技：天丼（はい、じゃんじゃん・なはん）、伏線回収（ふた）、たとえツッコミ、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：岩手県は面積が北海道に次いで全国 2 位で、本州でいちばん広い（早稲田大学の記事、旅行ガイド）。わんこそばは、お店の人が「はい、じゃんじゃん」「はい、どんどん」などと声をかけながら、食べ終わったお椀に次々とそばを入れ、おなかいっぱいになったらお椀にふたをするのが終わりの合図（かけ声は店によって違う。岩手の観光サイト、旅行記事）。南部鉄器は盛岡市・奥州市の鉄の鋳物で、鉄瓶が知られる（ANA の旅行ガイドなど）。方言「〜なはん」は「〜ね」（「んだなはん」＝そうですね）、「おでんせ」は「おいでください」（ウィキペディア「盛岡弁」）
# 気をつけたこと：岩手を「広いだけ」「遠い」といじらない（広いのは見どころが多いことの向き）。震災・津波にはふれない（名物と名所の楽しい回）。わんこそばのお店の人の仕事は、ちゃんとしている側（ずれているのはボケの使いどころだけ）。方言は好きでまねしている向き。実在の店・会社・人の名前は出さない。ほかの県の回（福井・岐阜・山口）が「旅の計画」なので、きっかけを変えた
