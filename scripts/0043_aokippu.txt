# 自転車の青切符。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「ルールを気にしすぎて、自転車を降りて押す距離のほうが長い」＋サブ（駅まで 2 キロで乗ったのは 30 メートル → 青信号でも降りる → 一時停止で 3 分 → スマホを家に置いてくる → 雨の日は自転車に傘 → 友達と縦に並んで押す → 今月の距離 → おまわりさんに声をかけられる）
# オチ：おまわりさんに「乗っていいですよ」と言われる → 「警察の人に、乗れって言われるな！」
# 技：エスカレーション（30 メートル → 3 分 → 家まで往復 → 押したのは 120 キロ）、たとえツッコミ（遠足か・引率の先生か）、一拍空け（「……それは本当だけど！」）
# 事実：2026-04-01 から、16 歳以上の自転車の交通違反に「青切符」（反則金）。対象は 113 種類で、反則金は 3000〜12000 円。ながらスマホは 12000 円（止まっているときの操作は対象外）。傘差し運転・並んで走る（並進）・一時不停止なども対象。自転車を押して歩く人は歩行者として扱われる
#   出典：大阪府警「自転車の交通違反に青切符」、柏市の案内、くるまのニュース（2026-03）、ベストカー Web（いずれも 2026 年に確認）
# 気をつけたこと：ルールを守る側に置く。ボケはルールを破らず、守りすぎてずれるだけ。ツッコミは正しいルール（止まって見るならいい・青は進め）を言い、ルール自体の良し悪しは言わない。おまわりさんは「ちゃんとしている」側（心配して声をかけてくれる）
