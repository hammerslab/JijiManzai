# 自動運転タクシー。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「行き先を伝えたあと、車と客だけで気まずい時間が流れる」＋サブ（行き先を言ったあと 15 分の沈黙 → 天気の話をしたらエアコンが下がる → ハンドルに会釈 → 音楽はウインカーの音 → 渋滞で客が謝る → 降りるときのお礼 → 星の評価）
# オチ：客は星 5 つで「もっと話したかったです」→ 次の日、車からの評価「星 3 つ。話しかけが、多めでした」→ 気まずかったのは車のほう
# 技：エスカレーション（沈黙 → 会釈 → 謝る → もう一回乗る）、すれ違い（話しかけ → エアコン・ウインカーで返ってくる）、伏線回収（話しかけ続けた → 車からの評価）
# 事実：運転席に人のいない自動運転タクシーは、海外の一部の街ではすでに営業している。日本では、東京で 2026 年後半から試験運行を始める計画が発表され（最初は安全のための人が乗る）、運転手なしの営業は 2027 年を目指す計画もある（2026-10 時点）
#   出典：ニュースイッチ・DX マガジン・ギズモード・ジャパン（2026 年の発表・報道）、Impress Watch。2026-10 の新しい動きは検索では見つからなかったので、台本では「東京でも試しに走らせる計画が進んでいる」とぼかした
# 気をつけたこと：会社名・サービス名・国名・街の名前は出さない（「海外旅行で乗った」だけ）。人の運転手さんは「ちゃんとしている」側（話しかけてくれる・謝ってくれる）に置き、仕事を奪う等の話にしない。笑うのは、機械に気をつかいすぎるボケだけ
