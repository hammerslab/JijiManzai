# 富山県（都道府県シリーズ）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 2：「富山の昆布じめをきわめたい男」×「覚えたての富山弁」。ボケは外から来た人で、覚えたての語尾「〜ちゃ（〜だよ）」を付け、「きときと（新鮮で生きがいい）」を 3 日寝かせたものに使う。「きのどくな（ありがとう）」も出てくる（抑揚は標準語のまま。まねなので不自然にならない）
# サブ（しょぼい → 大きい）：白えびの昆布じめを 3 日寝かせて「きときと」→ 何でも昆布じめ（ます寿し、ホタルイカ、プリン）→ 県の花のチューリップを昆布じめにしたら、春に昆布から芽が出る → 日本一高い黒部ダムを昆布じめにしたくて、北海道から船 1 そう分の昆布を取り寄せる（B が北前船と富山の昆布の話をして、A が「きのどくな」と正しく使う）
# オチ：いちばんの昆布じめは 3 年寝かせた → 見つめ合う → 昆布を昆布ではさんだ → B!!!（伏線回収：何でも昆布じめ・寝かせる）
# 技：言い間違い・勘違い（きときと）、エスカレーション（はさむものが大きくなる）、伏線回収（寝かせる・何でも昆布じめ）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：富山県は北陸。富山湾はブリ、シロエビ、ホタルイカ、紅ズワイガニの宝庫で、ます寿しも有名。チューリップは県の花（農林水産省「富山県の農林水産業の概要」令和 8 年版）。昆布〆は富山の郷土料理。昔、北前船の港があり、北海道の昆布が入ってきたので、昆布の料理が根づいた（農林水産省 北陸農政局「和食」冊子、うちの郷土料理）。立山連峰は 3000 メートル級の山が並ぶ。黒部ダムは高さ 186 メートルで日本一高いダム（政府広報オンライン、旅行情報サイト）。富山の言葉：「きときと」（新鮮で生きがいい。富山県の資料、富山商工会議所の方言番付）、文の終わりの「〜ちゃ」（〜です・〜だよ。富山大学の方言の資料）、「きのどくな」（ありがとう。All About、JLect）
# 気をつけたこと：富山を「何もない」「地味」といじらない。県のほうはちゃんとしている側で、ずれているのはボケのはさみ方だけ。実在の店・会社・人・ブランド名（お米やチューリップの品種名）、ゆるキャラ、有名な映画や歌の題名（ダムの映画など）は出さない。富山の薬など、ほかの名物はからかいに使わない
