# AIエージェント。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「AIエージェント」＋サブ（会議室の予約 → タスクの分解（会議室とは何か）→ 予約は 2 秒、報告が本番 → 進捗 0.5% を 5 つの観点で → 報告書 40 ページの目次 → コーヒー 1 杯に承認 7 回 → トークン節約の説明に 3000 字 → 別のエージェントの報告の要約の要約 → 一言で報告）
# オチ：「仕事は、全部、終わっています。昨日から」→「報告を読み終わっていない者が一人。あなたです。本日の残業、3 時間」→ 叩いて「お前の報告を読んでたからだろ！」
# 技：ノリボケ（B が頼み、A が AI エージェントを演じる）、天丼（「〜を定義します」「本当に、よろしいですか」）、エスカレーション、スカシ（見つめ合う →「全部、終わっています」）
# 事実：AIエージェント＝目的を伝えると、自分で計画を立てて、調べものやパソコンの操作まで進める AI。2026 年は「エージェントの年」と言われ、会社の業務に入り始めている（第一生命経済研究所のレポート、マイナビニュース 2026-01-08 ほか）
# 気をつけたこと：サービス名・会社名は出さない。からかうのは AI（を演じるボケ）だけで、使う人や会社員は笑わない。専門語（タスク・承認・トークン）はツッコミが一言で添える。
