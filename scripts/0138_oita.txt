# 大分県（都道府県シリーズ）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 2：「大分の温泉に全部入りたい男」×「覚えたての大分弁」。ボケは外から来た人で、覚えた大分の言葉（しんけん＝すごく、〜ちょん＝〜してる、よだきい＝めんどくさい）を取り違えたり、場面に合わない使い方をする（抑揚は標準語のまま）
# サブ（しょぼい → 大きい）：源泉 5000 以上を 1 日 1 つで 14 年 → 「しんけん」を「真剣」と思い、温泉でまじめな顔 → 「入っちょん」でふやける → かぼすをプリンにもしぼる → 別府の地獄めぐりにタオルを持っていく → 干ししいたけを温泉でもどす
# オチ：1 日目で「よだきい」→ お気に入りの 1 つに毎日通い、湯けむりを浴び続けた → 見つめ合う → 「髪が、こうなった」（アフロ）→ B!!!（伏線回収：しんけん を B が正しく使う、湯けむり）
# 技：言い間違い・勘違い（しんけん／真剣）、天丼（〜ちょん）、伏線回収（しんけん・湯けむり）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：大分県は九州の東側。温泉の源泉数（5,086 孔）と湧出量がどちらも全国1位で「おんせん県」と名のっている（大分県「大分県の日本一」令和5年度、県政概要2025）。かぼす（令和5年 6,500t）と乾しいたけ（令和5年 654t）の生産量も全国1位（大分県）。かぼすは全国の9割以上（農林水産省 九州農政局）。別府の地獄めぐりの海地獄・血の池地獄などは見て楽しむ温泉で、海地獄は約98度で入れない（別府地獄組合、大分県）。大分の言葉：「しんけん」（すごく）、語尾「〜ちょん」（「やっちょん」＝やってる）、「〜けん」、「よだきい」（めんどくさい）（大分県のマガジン「オオイタカテテ」の座談会、大分県の観光情報）
# 気をつけたこと：大分を「何もない」といじらない。県のほうはちゃんとしている側で、ずれているのはボケの使い方だけ。実在の店・会社・人・施設の名前は出さない。長湯や熱い湯をすすめない（ツッコミが止める）
