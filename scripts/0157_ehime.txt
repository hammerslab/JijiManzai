# 愛媛県（都道府県シリーズ）。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 2：「愛媛の歌を作りたい女」×「覚えたての伊予弁」。ボケは外から来た人で、愛媛のいいところを歌にしたい。覚えたての「やけん（だから）」で歌詞を全部終わらせ、「むぐ（皮をむく）」を服やタオルにまで使い、「かまん（かまわない・大丈夫）」を「我慢」だと思う（抑揚は標準語のまま。まねなので不自然にならない）
# サブ（しょぼい → 大きい）：歌詞の終わりが全部「やけん」→ 一番：みかんを「むぐ」、服も「むぐ」→ 二番：今治のタオルが歌詞まで吸う → 三番：道後温泉で「かまん、かまん」と熱いのを我慢・湯船で歌う → 四番：マダイは「めで鯛」
# オチ：通しで歌うと、歌詞がツッコミのことばばかり → 見つめ合う →「あんたの、ツッコミで、できた」→ B!!!（伏線回収：それまでのツッコミ全部）
# 技：天丼（やけん）、伏線回収（ツッコミが歌詞になる）、言い間違い・勘違い（かまん＝我慢）、見つめ合う（オチの前）、「」@cute は歌うところだけ 1 回
# 事実（2026-11-18 時点）：愛媛県は四国の西側。みかんなどのかんきつで知られ、道後温泉（日本でいちばん古いといわれる温泉のひとつ）、松山城。タオルの生産量は日本一（今治市のポケット統計）、養殖マダイの生産量も日本一（JETRO の 2025 年の記事で 33 年連続 1 位、総務省の資料）。伊予弁の「けん・やけん」は「から・だから」、「むぐ」は「むく（皮をむく）」、「かまん」は「かまわない・よい」（Wikipedia「Iyo dialect」。出典は『今日の伊予弁』）。（かんきつの順位は年でかわるので台本では言わない）
# 気をつけたこと：愛媛を「何もない」「地味」といじらない。有名な小説の「ぞなもし」や、実在の歌・ゆるキャラ・店・会社・商品の名前（タオルや柑橘のブランド名など）は出さない。歌はボケが自分で作ったことばだけで、実在の県の歌にはふれない。温泉ではマナーを守る向き（ツッコミが止める）
