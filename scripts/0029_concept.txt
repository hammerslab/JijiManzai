# コンセプトシティ。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「コンセプトシティ」＋サブ（壮大なコンセプト → スーパーの代わりに「食について考える場所」→ 病院の代わりに「ウェルビーイングの森」→ まっすぐな道が一本もない → 移動は全部空飛ぶクルマ・免許は誰も持ってない → ゴミをアートとして広場に飾る → 住民はゼロ）
# オチ：住民がみんな「スーパーと病院はどこ？」と聞いて帰ったので、計画を作り直した。完成予想図は「駅前にスーパーと病院がある街」＝ B の住んでいる街。B!!!
# 技：天丼（B が住民役で「スーパーと病院はどこ？」を何度も聞く。最後は A の口から住民の声として出る）、ノリボケ（B が移住を考える人を演じる）、伏線回収（B の住んでいる街）
# 事実：「コンセプトシティ」は、街全体に一つのテーマ（コンセプト）を決めて、ゼロから作る新しい街づくりのこと。決まった定義の数字や事例には頼らず、言葉の意味とあるあるだけで作った
# 気をつけたこと：実在の街・計画・会社の名前は出さない。街づくりの仕事をしている人を笑いものにせず、おかしいのはボケ本人の考えた街だけ。「スーパーと病院はどこ？」と聞く住民は、正しい側に置いた
