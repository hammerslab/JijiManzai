# 公園の看板。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「公園の看板を全部守りすぎて、できる遊びを探す男」＋サブ（ボール遊び禁止 → 丸いものを全部置いてくる、アフロも四角い帽子で隠す → 大きな声を出さない → ずっと小声で、ブランコが空かない → 芝生に入らない → 家の緑のじゅうたんもまたぐ → ベンチで寝ない → 眠くなるから座らない → 残った遊びは「立つ」→ 子どもに鬼ごっこのセーフの木だと思われる）
# オチ：ひとりで立つのがさみしくなり、「2 人で並んで立って、大きな声を出してもいいところ」を見つけた → 見つめ合う →「ここ。」→ B!!!「漫才を、立ってるだけの遊びだと思うな！」
# 技：エスカレーション（看板を 1 枚ずつ）、スカシ（残ったのは「立つ」→「……遊びじゃないだろ」）、伏線回収（大きな声・立つ → 漫才の舞台）、見つめ合う（「立つ」の前）
# 気をつけたこと：公園や自治体、看板をけなさない（看板は近所の人や小さい子が安心して使えるためのもの、とツッコミが最初に言う）。おかしいのはボケの探し方と守りすぎ。近所の人や子どもも笑いものにしない
