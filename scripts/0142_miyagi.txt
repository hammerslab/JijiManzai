# 宮城県（都道府県シリーズ）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 2：「宮城の物産展を開きたい男」×「覚えたての宮城の言葉」。ボケは外から来た人で、宮城の「いきなり（すごく）」をチラシに書いて「急に」と読まれ、「いずい（しっくりこない）」「おしょしい（恥ずかしい）」も出てくる（抑揚は標準語のまま。まねなので不自然にならない）
# サブ（しょぼい → 大きい）：チラシに「いきなり、物産展、開きます」で誰も来ない → 笹かまぼこを笹の葉で包んで笹に下げたら、七夕の飾りと間違えられて願いごとを書かれる → ずんだを全部にかける（お茶にも、のぼりにも。B が「いずい」と正しく使う）→ 日本一のせりで、根っこだけのせり鍋 → 店番にこけし 100 体、お客が目が合って帰る → 目玉の松島は、床に水を張っておにぎりを浮かべる
# オチ：チラシを「いきなり、牛たん、あります」に書き直したらお客がいっぱい → 見つめ合う → 牛たんを出すのを忘れていた、「おしょしい」→ B!!!（伏線回収：いきなりのチラシ。一番の名物を忘れる）
# 技：言い間違い・勘違い（いきなり）、ノリツッコミ（おにぎりの松島）、エスカレーション（物産展の品が大きくなる）、伏線回収（チラシ・牛たん）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：宮城県は東北の太平洋側。牛たん焼きは仙台の名物（仙台観光国際協会「仙台 食物語」、宮城県観光連盟）。笹かまぼこは白身魚のすり身を笹の葉の形にして焼いたもの、ずんだは枝豆をすりつぶしたあん（同）。仙台七夕まつりは笹飾り。養殖のぎんざけとせりは収穫量が全国 1 位、せり鍋は根まで食べる（農林水産省「宮城県の農林水産業の概要」令和 8 年版）。松島は日本三景のひとつで、湾に島が多く浮かぶ。こけしは宮城の伝統工芸。宮城の言葉：「いきなり」（すごく）、「いずい」（しっくりこない・違和感がある）、「おしょしい」（恥ずかしい）（日本旅行「トリッパ」宮城の方言、辞書）
# 気をつけたこと：宮城を「何もない」といじらない。震災・津波など災害にはふれない（沿岸の地名も出さない）。県のほうはちゃんとしている側で、ずれているのはボケの使い方と並べ方だけ。実在の店・会社・人・ブランド名、ゆるキャラ、アニメの決めぜりふ（「〜だっちゃ」は使わない）、有名な歌の題名は出さない。こけしはからかわず、かわいいもの・目ぢからのあるものとして扱う
