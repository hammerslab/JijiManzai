# M&A（会社の買収）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「M&A」＋サブ（社員 1 人の会社が買収 → 「家族になろう」→ 待遇は家族だからない → 給料はお小遣い・ボーナスはお年玉 → 休みは社長の実家に帰省 → デューデリジェンスで社員の好物を調べる → 社員のご両親にあいさつ → シナジーは全部俺の手柄 → このコンビを子会社に）
# オチ：買収先は「このコンビ」。「家族になろう」に、B が本気で「まず、待遇を確認させてくれ」→「ギャラは 9 対 1」で B!!!
# 技：天丼（「家族になろう」→「まず待遇を確認させて」を最初とオチの 2 回。2 回目は芝居ではなく本気）、ノリボケ（B が買われた側の社員を演じる）、伏線回収（「どこを買うんだよ」→ もう買った・このコンビ）
# 事実：日本の会社が関わる 2025 年の M&A は 5115 件で、2 年連続の過去最多・初めて 5000 件超え（レコフデータの集計。共同通信 2026-01-05）
# 気をつけたこと：実在の会社名・買収の事例は出さない。買われた側の社員は「待遇を確かめる、ちゃんとした人」の側に置き、おかしいのは「家族」でごまかすボケの社長だけ。M&A そのものの良し悪しは言わない
