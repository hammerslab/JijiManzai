# しゃばい。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 1：メイン「何でも『しゃばい』の一語で片づける」＋サブ（映画 → パスタのお店 → カレー（しゃばしゃば） → AI の感想 → おばあちゃんに教える → 「しゃばい」以外で言うと意味の並べ読み → 読書感想文 → 山の朝日 → 相方のツッコミだけ細かい）
# オチ：相方のツッコミについてだけ急に細かく語る → 言われた B が「……しゃばい」と使ってしまう → A「使い方、合ってる」→ 叩いて「うつっちゃったじゃーーん！」
# 技：天丼（「具体的には？」→「しゃばい」）、言い間違い（しゃばい／しゃばしゃば）、緩急（一語ばかりのボケが、最後だけ長く話す）、伏線回収（おばあちゃんにうつる → 相方にうつる）
# 事実：「しゃばい」＝冴えない・かっこわるい・ださい、という意味の若者言葉。三省堂「今年の新語 2025」（2025-12-03 発表、大賞は「ビジュ」）で、応募された言葉の中から取り上げられた（文藝春秋 電子版のコラム、KAI-YOU、Oggi.jp）。上位 10 語に入ったかは確かめられなかったので、台本では「候補に挙がった」とだけ言う。語源は確かな出典がないので言わない
# 気をつけたこと：「しゃばい」と言われるのは物（映画・料理・AI の文）とボケ本人の作文だけ。相方の見た目や、実在の作品・店は出さない。意味を先に説明してから使う
