# 京都府（都道府県シリーズ）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 2：「京都の修学旅行を引率したい男」×「覚えたての京都の言葉」。ボケは先生ではない外の人で、相方を生徒にして引率ごっこをする。覚えたての「〜どす」を何にでも付け、人を敬う「〜はる」を自分に付け、迎える側の「おいでやす」を自分が言う（抑揚は標準語のまま。まねなので不自然にならない）
# サブ（しょぼい → 大きい）：「どす」を付けすぎる → 自分に「はる」 → 金閣寺の入り口で「おいでやす」→ 千本鳥居をくぐるたびに点呼 → 湯豆腐を先生が全部食べはった → 碁盤の目の町で生徒を白黒の帽子で交差点に立たせて囲碁
# オチ：記念写真に先生がいない → 見つめ合う →「先生が、迷子に、なってはった」→ B!!!（伏線回収：自分に「はる」・点呼・碁盤の目は通りの名前で場所が分かる町）
# 技：天丼（自分に「はる」、「どす」が戻る）、伏線回収（点呼・はる）、ノリボケ（囲碁）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：京都は修学旅行の定番で、金閣寺・清水寺・伏見稲荷大社の千本鳥居、八つ橋、宇治の抹茶、湯豆腐が知られる。町は通りが縦横にまっすぐ通る碁盤の目で、通りの名前で場所を言う。京ことばの「〜はる」は人（身内や動物にも）を敬って言う代表的な敬語、「〜どす」は今では高齢の人や花街など限られた場面で聞かれる、「おいでやす」は迎えるあいさつ（Wikipedia「京言葉」、京都の観光案内、fun-japan）
# 気をつけたこと：「いけず」「本音と建前」など府民性をからかうネタはしない。お寺・神社は観光地として紹介するだけで、からかわない（ボケたのは「おいでやす」と点呼で、建物や信仰ではない）。舞妓さんは「どす」を聞く場面として名前を出すだけ。実在の店・会社・人の名前は出さない
