# 振り込め詐欺（疑いすぎる男）。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「振り込め詐欺」＋サブ（電話は全部詐欺だと思う → 母ちゃんの電話に合言葉、答えを忘れたのは自分 → 「俺だけど」に「俺だけど」で根比べ → 警察官のふりの電話 → 本物のおまわりさんに警察手帳と合言葉 → ピザ屋さんを家族に相談 → ばあちゃんは正しい → 相方のスタジオ代）
# オチ：相方の「スタジオ代、半分振り込んで」を、一回切って警察に相談 → 「相方を通報するな！」。そのあと B が短く注意して締める
# 技：天丼（合言葉・「一回切って、相談した」・おまわりさんは優しい）、エスカレーション（母ちゃん → 知らない人 → おまわりさん → ピザ屋 → 相方）、伏線回収、見つめ合う
# 事実：警察庁のまとめで、2025 年の特殊詐欺の被害額は約 1423 億円で過去最悪。警察官を名乗る「ニセ警察詐欺」が約 7 割を占めた（nippon.com・秋田魁新報、2026-02）。台本では数字は出さず「去年は過去で一番多かった」「警察官のふりの電話も多い」だけにした
# 気をつけたこと：手口は「家族や警察のふりをして電話し、お金を払わせる」の一言だけ。まねできる細かさは書かない。お年寄りや被害にあった人を笑わない（ばあちゃんは一番ちゃんとしている側）。おまわりさん・ピザ屋さんも優しくちゃんとしている側。笑うのは疑いすぎるボケだけ。最後に B が「家族や警察、公式の窓口に相談」と注意する
