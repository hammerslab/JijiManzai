# 愛知県（都道府県シリーズ）。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 2：「愛知で喫茶店を開きたい女」×「覚えたての名古屋の言葉」。ボケは外の人で、覚えた「いりゃあせ（いらっしゃい）」を帰るお客さんにも言い、「でら（とても）」をメニュー全部に付け、「〜だがね（〜だよね・〜じゃない、と念を押す）」を使う（抑揚は標準語のまま）
# サブ（しょぼい → 大きい）：帰るお客さんにも「いりゃあせ」→ モーニングのゆで卵が 10 個 → 「でら、お水」→ ひつまぶしの 3 通りの食べ方をコーヒーで（3 杯目にだし）→ 名古屋城の金のしゃちほこの代わりに、自分が屋根にのる
# オチ：開店の日、帰ろうとするお客さんに「いりゃあせ」→ また入ってくる → またモーニングが付く → 見つめ合う → 朝から晩までずっとモーニング → B!!!（伏線回収：帰る人にもいりゃあせ、ゆで卵 10 個）
# 技：天丼（いりゃあせ）、伏線回収（帰る人にいりゃあせ・ゆで卵）、エスカレーション、見つめ合う（オチの前）。3 分に収めるため、小倉トーストのあんこがパンの 10 倍のくだりは外した
# 事実（2026-11-18 時点）：愛知の喫茶店では、午前中に飲み物を頼むとトーストやゆで卵が付くモーニングが一般的で、一宮市は「モーニング発祥の地」とされる（愛知県公式観光サイト Aichi Now「喫茶愛あふれる一宮モーニングの世界」）。小倉トーストは名古屋の喫茶店から広まったといわれる（和樂web ほか）。ひつまぶしは、そのまま → 薬味 → だし茶漬けと 3 通りで楽しむ。名古屋めしには味噌カツ・手羽先・きしめんなど（名古屋市公式観光サイト「名古屋コンシェルジュ」ほか）。名古屋城の天守には金のしゃちほこがのる（観光ガイド各種）。名古屋の言葉：「でら」（とても・すごく）、「いりゃあせ」（いらっしゃい）（名古屋市公式サイト）、「〜だがね」「〜だで」（愛知学院大学の資料で名古屋の言葉の例として挙げられる）
# 気をつけたこと：愛知・名古屋を「派手好き」「けち」といじらない。有名な会社・商品・お店・お菓子の名前は出さない（「喫茶店」「モーニング」「小倉トースト」は一般の名前）。名古屋の言葉の「〜みゃあ」のような、からかいに使われがちな言い方は使わない。県のほうはちゃんとしている側で、ずれているのはボケの店の作り方と言葉の使い方だけ
