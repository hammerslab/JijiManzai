# 寝落ち。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「寝落ちにあこがれて練習する男」＋サブ（毎晩、天井に「寝ます」と言ってから寝る → スマホを顔に落とす練習を 100 回、痛くて眠れない → 寝落ち通話で相方が先に寝て、朝までいびきを聞く → 首を「かくん」とするポーズを 1 日 300 回 → 一番眠くなる動画を全部見比べて 3 日寝ない → 本番の日を決め、目覚ましをかけ、緊張して一睡もできない）
# オチ：相方が「寝落ちは練習するものじゃない」とゆっくり長く説教する → 長い間 →「……ぐう。」→「お前の話、よく、眠れる」（伏線：寝落ち通話で相方が先に寝た）→ B!!!「今、寝落ちするな！」
# 技：伏線回収（相方の話で寝る）、スカシの間（説教のあとの長い沈黙）、緩急（ツッコミのゆっくりした説教）、エスカレーション（練習 → 本番）、見つめ合う（寝落ち通話の種明かしの前）
# 気をつけたこと：眠れない人を笑いものにしない（おかしいのはボケの練習のしかた）。体に悪いことをすすめない（首やスマホはツッコミが止める）。0066 マウント（寝てない自慢）とかぶらないよう、自慢ではなく「練習」に絞った
