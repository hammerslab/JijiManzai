# 秋田に移住したい女

- お題：秋田県
- コンビ：女性　ボケ・ボブ／ツッコミ・ギャル
- 長さ：3分03秒（VOICEVOX の声で作ったとき）

記号：〔間〕＝少し黙る、【叩く】【強く叩く】【思いきり叩く】＝手刀でツッコむ（効果音つき。頭の「えぐーー！」は自動で付く）、〈〉＝そこだけ声を変える

**2 人**　どうもー、よろしくお願いしますー！

**ツッコミ・ギャル**　ねえ、秋田県って、行ったことある？ 東北の日本海側で、きりたんぽとか、稲庭うどんとか、男鹿のなまはげとか、有名なもの、いっぱいあるじゃん！

**ボケ・ボブ**　〔間〕私、秋田に、移住したい。

**ツッコミ・ギャル**　え、いいじゃん！ 本気？

**ボケ・ボブ**　〔間〕んだ。

**ツッコミ・ギャル**　お、「んだ」は、「そうだよ」ってことね。もう、秋田弁、使ってるじゃん！

**ボケ・ボブ**　〔間〕お茶っこ、飲む？

**ツッコミ・ギャル**　あー、「っこ」ね。小さいものとか、かわいいものに付けて、親しみをこめる言い方なんだよね。

**ボケ・ボブ**　〔間〕飴っこ。

**ツッコミ・ギャル**　かわいい。

**ボケ・ボブ**　〔間〕犬っこ。

**ツッコミ・ギャル**　秋田犬かな。かわいいじゃん。

**ボケ・ボブ**　〔間〕請求書っこ。

**ツッコミ・ギャル**　【叩く】えぐーー！ 請求書は、かわいくならないじゃーん！ 金額は、そのままじゃん！

**ボケ・ボブ**　きりたんぽも、作った。

**ツッコミ・ギャル**　つぶしたごはんを、杉の棒に巻いて、焼くやつね。お鍋に入れても、おいしいんだよ。

**ボケ・ボブ**　〔間〕杉の棒が、なかったから、

**ツッコミ・ギャル**　うん。

**ボケ・ボブ**　〔間〕リコーダーに、巻いた。

**ツッコミ・ギャル**　吹けなくなるじゃん！ 音楽の時間、ごはんのにおいしか、しないじゃん！

**ボケ・ボブ**　竿燈まつりも、見た。

**ツッコミ・ギャル**　夏のお祭りね。長い竿に、提灯を、いっぱいつけて、手のひらとか、おでことか、腰で、支えるんだよ。一番大きいのは、12メートルで、50キロもあるんだって。

**ボケ・ボブ**　〔間〕私も、練習してる。竿燈っこで。

**ツッコミ・ギャル**　小さいのね。何で作ったの？

**ボケ・ボブ**　〔間〕ストローに、ポチ袋を、つけた。

**ツッコミ・ギャル**　【叩く】えぐーー！ 軽すぎじゃーん！ くしゃみしたら、飛んでいくじゃん！

**ボケ・ボブ**　男鹿の、なまはげにも、会った。

**ツッコミ・ギャル**　大みそかに、「泣く子は、いねがー」って、家を回るんだよね。

**ボケ・ボブ**　〔間〕「なまはげっこ」って、呼んだ。

**ツッコミ・ギャル**　かわいく、しないで！

**ボケ・ボブ**　〔間〕頭を、なでた。

**ツッコミ・ギャル**　【強く叩く】えぐーー！ 子犬じゃないじゃーん！ なまはげのほうが、どうしていいか、分からなくなるじゃん！

**ボケ・ボブ**　田沢湖にも、行った。

**ツッコミ・ギャル**　日本で、一番、深い湖ね。423メートルも、あるんだよ。

**ボケ・ボブ**　〔間〕田沢湖っこ。

**ツッコミ・ギャル**　【強く叩く】えぐーー！ 日本一深いのに、小さくしないで！ 「っこ」付けるところじゃ、ないじゃーん！

**ボケ・ボブ**　移住の、準備も、できた。

**ツッコミ・ギャル**　お、荷物は、まとめたの？

**ボケ・ボブ**　〔間〕荷物っこ、少しだけ。

**ツッコミ・ギャル**　えらいじゃん、身軽で。何を持っていくの？

**ボケ・ボブ**　〔間〕竿燈、1本。

**ツッコミ・ギャル**　ああ、ストローのやつね。

**ボケ・ボブ**　〔間〕12メートルの、ほう。

**ツッコミ・ギャル**　【思いきり叩く】えぐーー！ 一番大きいの、持っていくじゃーーん！ そっちこそ、「っこ」付けるところじゃん！ ……でも、それくらい、秋田が好きってことか。いや、引っ越しのトラックに、入らないじゃん！ もういいよ！

**2 人**　どうも、ありがとうございましたー！
