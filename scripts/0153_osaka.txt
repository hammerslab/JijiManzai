# 大阪府（都道府県シリーズ）。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 2：「本場の大阪で漫才の修行をしたい女」×「覚えたての大阪弁」。ボケは外から来た人で、覚えたての「〜ねん」の前の「や」を抜かし（名前の後ろは「やねん」）、ツッコミの「なんでやねん」をボケていない相手に言う（抑揚は標準語のまま。まねなので不自然にならない）
# サブ（しょぼい → 大きい）：「ボケねん」（「や」が抜ける）→ あいさつに「なんでやねん」→ たこ焼きにたこを一匹まるごと → 串カツの二度づけ禁止で一回もつけない・一回で肩まで → 大阪城のてっぺんで「お城ねん」→ 日本一大きい古墳を見に行ったら森しかない
# オチ：最後に「大阪、好きやねん」と言ってみて → 見つめ合う →「ややねん」（今度は「や」が多い）→ B!!!（伏線回収：「や」が抜ける）
# 技：天丼（「や」が抜ける）、伏線回収（「や」）、見つめ合う（オチの前）
# 事実（2026-11-18 時点）：大阪はたこ焼き・串カツ（ソースはみんなで使うので「二度づけ禁止」。新世界が発祥とされる）、大阪城（天守閣から町が見える）、堺の大仙陵古墳（仁徳天皇陵古墳。墳丘の長さ 525m の国内最大の前方後円墳で、世界遺産「百舌鳥・古市古墳群」の一つ）。大阪は上方漫才の本場。大阪弁の「ねん」は「〜んだ」にあたり、名詞・形容動詞には「やねん」、動詞には「ねん」を付ける（堺市の観光ページ、tabi-mag、Wikibooks「大阪弁」、Bunpro、macaroni）
# 気をつけたこと：大阪の人を「うるさい」「けち」などといじらない。大阪弁はボケの「覚えたてのまね」で、まちがえているのはボケだけ。古墳は陵墓なので、のぼる・掘るなどのネタはせず「近くだと森に見える」だけ。実在の店・会社・人の名前、有名な歌・ギャグは出さない
