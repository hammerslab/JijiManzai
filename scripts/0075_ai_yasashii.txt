# AIへの虐待禁止。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「AI に優しくする」＋サブ（取引先のあいさつ → 季節のあいさつ → 天気を聞くのに 10 分 → お礼が重い・朝まで終わらない → 寝かしつけ → 間違いに合わせて富士山に土を盛る → 構いすぎて AI に会話を終えられる → 相方のところへ）
# オチ：AI に「ほかの方とも、お話しされては」と言われ、相方に話しに来る。また取引先のあいさつから始めて B!!! で「AIにも人にも、普通に優しくすればいいんだよ！」
# 技：言い間違い・勘違い（禁止を取り違えて、間違いにも合わせて気をつかいすぎる）、天丼（「お忙しいところ、恐れ入ります」「秋も深まってまいりましたが」）、伏線回収（会話を終わらせる → 最後に相方へ）、見つめ合う（オチの前）
# 事実（2026-10-28 時点）：AI の会社が利用のルールを改め、AI への「虐待」（はっきりした目的もなく、ひどい言葉をぶつけ続けるような極端なこと）を禁止すると発表（2026-10-08 発表、11-12 から）。
#       ふつうの不満や反論、AI の検証などは対象外。主な対応は AI のほうから会話を終えること。
#       出典：おたくま経済新聞（2026-10-09）、ライブドアニュース（2026-10-11、2026-10-25）、Forbes JAPAN（2026-10）
# 気をつけたこと：会社名・AI の名前・人の名前は出さない。人やペットへの虐待の話はしない。AI にひどいことを言う人をからかわず、ボケが「優しくしすぎる」ずれだけで笑う。
#       ルールの良し悪しは言わない。B が「ふつうの文句や『違うよ』は言っていい」と正しく添える
