# エッホエッホ。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「エッホエッホ、〇〇って伝えなきゃ」＋サブ（自分の靴ひも → 1 週間は 7 日 → 牛乳に牛乳の残りを → スマホで送ったと走って伝える → 夜中の 3 時に「まだ夜です」 → 何を伝えるか忘れる → 地球の反対側へ「こっちは夜」 → 相方の靴ひも → もういいよ）
# オチ：最後にやっと役に立つこと（相方の靴ひもがほどけている）を伝えたあと、「もういいよって、伝えなきゃ」→ 叩いて「それは俺が言うんだよ！」
# 技：天丼（「エッホエッホ」・靴ひも）、スカシ（見つめ合う → 「……あ、ほんとだ」）、伏線回収（自分の靴ひも → 相方の靴ひも）、エスカレーション（伝える相手がどんどん遠く・大きくなる）
