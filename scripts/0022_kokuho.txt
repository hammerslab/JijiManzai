# 国保の督促状。男性コンビ。A＝ボケ（痩せたアフロ・淡々）／B＝ツッコミ（太ったモヒカン）
# 型 1：メイン「目立ちすぎる督促状の封筒」＋サブ（「開封」がびっしり → 「あけろ」と言われると開けたくない → 裏に目 → アフロにしまう → 差出人を確かめる（消印・虫めがね・透かす） → 公式の番号に電話して本物と分かる → 中身が普通すぎて逆にこわい → 窓口で払う・相談する → お礼の手紙）
# オチ：役所へのお礼の手紙の封筒に、ボケが「開封」と 100 回書いた。「お前が送り返すな！ 今度は役所が警戒するだろ！」
# 技：天丼（「まず、差出人を、確認しよう」を 3 回）、伏線回収（「開封」がびっしり → 最後にボケが同じことをする）、たとえツッコミ（お化け屋敷か）、スカシ（中身が普通すぎて、こわい）
# 事実：ある区の国民健康保険料の督促状の封筒が、「開封」「あけろ！」の文字や顔文字、目のイラストでびっしりのデザインで、ネットで「不気味」と話題になった。区によると、使い始めてから収納率が約 88% から約 96% に上がった一方、区は「配慮が足りなかった」としている（FNNプライムオンライン 2026-10-20、ABEMA TIMES）
# 気をつけたこと：自治体名・報道機関名は出さない。実際の封筒や役所・職員を責めず、制度の良し悪しも言わない（笑うのは、ボケの警戒しすぎと、ボケの頭の中でふくらんだ封筒だけ）。払わない話をすすめない：最後はボケが窓口で払い、払えないときは窓口に相談、と B が言う。差出人を公式の番号で確かめるのは正しい行い、と B が認める
