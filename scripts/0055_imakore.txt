# 「〇〇で今これ」。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 1：メイン「どんな状況も、写真と一言で報告する」＋サブ（起きて今これ＝毎朝同じ天井 → ラーメンを 37 枚撮り直して伸びる → 遅れて今これ＝自分のベッド → 楽屋で相方を撮る → お母さんと同じテーブルで報告し合う → 容量いっぱいで絵を描いたら 3 時間＝もう今じゃない → 漫才が終わったところを撮りたい）
# オチ：「漫才終わって今これ」を撮りたくて早く終わらせたい → 最後に叩かれるところも撮りたくて、自分から頭を出す。叩いて「叩かれ待ちじゃーーん！」
# 技：エスカレーション（報告のために生活がずれていく）、天丼（天井の写真）、たとえツッコミ（間違い探し）、伏線回収（「今」じゃなくなる →「さっきこれ」）
# 事実：「〇〇で今これ」＝写真に短い一言を添えて、いま何をしているかを伝える SNS の言い回し。調べても、決まった由来や数字の資料は見つからなかったので、あるあるだけで作った
# 気をつけたこと：写真を上げる人を笑わない。お母さん・お父さんの家族も悪く言わない（お父さんは「ちゃんとしている」側）。相方の見た目はからかわない（写真は顔を撮るだけ）。人の顔を勝手に上げる話は、相方（身内）だけにして軽く
