# ファストパス。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 1：メイン「ファストパス」＋サブ（ファストパスを取る列に 2 時間 → ファストパスの列が一番長い → ファストパス・プラス → プラス・プラス → どの列が一番早いか計算して閉園 → 3 万円使って 1 個も乗ってない → スーパーのレジでも隣の列が早い → 全部の列に少しずつ並ぶ）
# オチ：やっと見つけた一番早い列は「出口」。B!!!「帰ってるじゃーーん！」
# 技：天丼（「プラス」がどんどん増える）、エスカレーション（列の数とお金が増える）、畳み掛け（列の名前の言い合い）
# 事実：テーマパークでは、お金を払って行列を早く抜ける券（有料の優先パス）が広がっている。2026 年は主なテーマパーク・遊園地の約 3 割がチケット代を値上げし、乗り放題のフリーパスの平均が初めて 5000 円を超えた（帝国データバンクの調査。nippon.com・マイナビニュース 2026-07）。細かい数字はネタの芯にしない
