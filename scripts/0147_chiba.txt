# 千葉県（都道府県シリーズ）。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 2：「千葉の物産展を開きたい女」×「覚えたての千葉の言葉」。ボケは外の人で、覚えた「あんでんかんでん（何でもかんでも）」で何でも並べ、「〜だっぺ（〜でしょ）」を付け、「おっぺす（押す）」を案内に使うのに自分が押す（抑揚は標準語のまま）
# サブ（しょぼい → 大きい）：日本一のマッシュルームを頭にのせてボブと見分けがつかない → 落花生を木からもいだと言い、会場の床を掘る → いせえびを「ちばえび」に書きかえる → 「おっぺさないで」の練習で相方をずっと押していた
# オチ：あんでんかんでん並べたら、自分にも値札「ジャンボマッシュルーム」が付いていた → 見つめ合う → B!!!（伏線回収：マッシュルームを頭にのせた、あんでんかんでん）
# 技：伏線回収（マッシュルーム・あんでんかんでん）、見つめ合う（オチの前）。3 分に収めるため、梨の看板を「なし」とひらがなで書くくだりは外した
# 事実（2026-11-18 時点）：千葉県はらっかせい（全国の収穫量の約 8 割強）、日本なし、だいこん、マッシュルームなどの収穫量が全国 1 位。マッシュルームは 10cm 前後のジャンボマッシュルームも作られる。いせえびの漁獲量も全国 1 位（農林水産省「千葉県の農林水産業の概要」令和 7 年版・2026 年版、千葉県「落花生」Q&A）。落花生は花がしぼむと子房柄が伸びて土にもぐり、地中で実をつけるのが名前の由来（千葉県・千葉県落花生協会の資料）。九十九里浜は約 66km の砂浜（国土交通省、JNTO）。千葉の言葉：「あんでんかんでん」（何でもかんでも）、「おっぺす」（押す。「おっぺっさないで」）（千葉市「あんでんかんでん」）、「〜だっぺ」（〜でしょ。「そうだっぺ」）（日本旅行、千葉市の記事）
# 気をつけたこと：千葉を「何もない」「東京のおまけ」といじらない。テーマパークの名前・中身は出さない。県のほうはちゃんとしている側で、ずれているのはボケの並べ方と言葉の使い方だけ。実在の店・会社・人の名前は出さない。いせえびの名前の元の土地もからかわない
