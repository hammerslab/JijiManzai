# ゆるキャラのアニメ映画大ヒット。女性コンビ。A＝ボケ（小さく痩せたボブ・低く淡々）／B＝ツッコミ（小太りの金髪ギャル）
# 型 1（ノリボケ）：メイン「映画が大ヒットしたゆるキャラ」をボケが演じ、ツッコミが聞き手になる。サブ（マネージャーを通して → 語尾の「ほく」を卒業 → 手を振るのは宣伝の日だけ → 楽屋のこだわり → 役作りでやせる → 海外向けの名前 → 記者会見 → 商店街の子どもの手紙 → ギャラ）
# オチ：子どもの手紙で「……ほく。」とゆるさが戻り、商店街で風船を配ると言う →「ギャラは、映画と同じで。」→ そこはゆるくしてよ！
# 技：ノリボケ（B の「じゃあやってみてよ」→ A が大物を淡々と演じる）、天丼（フライドポテト＝共食い）、伏線回収（商店街の風船 → 手紙 → 最後のギャラ）、スカシ（「……ほく。」）
