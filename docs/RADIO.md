# ほのぼの週刊ラジオ（試作中）

漫才とは別に、その週の話題を 4 人で話す 10 分ほどの動画。2026-10-28 利用者と決めた大まかな形。まだ試作の前なので、作りながら直す。

- 番組名：**ほのぼの週刊ラジオ**（「週刊」に決めた。2026-10-28 利用者）
- 登場：男性コンビ・女性コンビの 4 人。背景はラジオのブース（机・マイク 4 本・ON AIR のランプ）
- 長さ：10 分前後（1 話題 2 分くらい × 4 話題＋前後のあいさつ）。8 分を超えると、途中に広告を入れられる

## 1 つの話題の流れ

漫才より、**話題の中身が分かること**を大事にする。

1. **見出し**：画面に「今週の話題①　〇〇」
2. **ニュースを読む**：読み手が、見出しと要点を 2〜3 文で読む。聞き手が合いの手を入れて、会話の形にする
3. **たとえ話**：難しい話題は、身近なものにたとえる。例：VPS 経由で利用者の PC に入られたニュース →「VPS はホテルの 1 室。管理人の合鍵が誰でも使える状態だった」
4. **意見とボケ**：キャラのずれで笑う（実在のものはいじらない）
5. **ひとことで締める**：役に立つ一言（「パスワードの使い回しはやめようね」など）で次の話題へ

## 役（案）

- 読み手：女性ツッコミ（金髪ギャル）。読むときだけまじめになる
- たとえ係：男性ツッコミ（モヒカン）
- ボケ：アフロとボブ（勘違いと脱線）

## 固有名詞と、扱わない話題

- **入れてよい**：会社名・商品名・サービス名・イベント名・地名・スポーツの結果など、事実をそのまま言うもの
- **入れない**：政治（選挙・政党・政策の良し悪し）、宗教、事件・事故・災害の被害、芸能人のゴシップ、実在の個人や会社への批判や持ち上げすぎ（声の規約。[VOICEVOX.md](VOICEVOX.md)）
- 意見は「〇〇社がひどい」ではなく「こういうことが起きるから気をつけよう」の向きにする
- セキュリティの話題は、手口をまねできる細かさで書かない
- 記事の文や写真は使わない。事実を自分の言葉で言い直し、説明欄に出典を書く。台本の頭にも出典（媒体名と日付）を書き、数字・日付・社名を確かめてから声を作る

## ショート（テレビ CM 風）

ダイジェストではなく予告。「今週のほのぼの週刊ラジオは、〇〇と〇〇の話題！」→ 本編の見どころを 10〜15 秒 →「本編は〇曜 〇時！」。本編と同じ日か少し前に出す（漫才のショートの「毎週月曜に先週分」とは別）。

## 話題の集め方（案）

1. 週の後半に、Claude が WebSearch で候補を 15 個ほど集める。分野を決めて探す：IT・セキュリティ、新商品・サービス、食べもの、流行・ネット、スポーツ、季節の行事、経済の明るい話題
2. 探す先の例：大きなニュースサイトのランキング、検索の急上昇ワード、IT 系のニュースサイト、企業のプレスリリースの配信サイト
3. 上の「入れない」に当たるものを外し、候補を表（見出し・分野・出典と日付・たとえ話の案）にして利用者に見せる
4. 利用者が 4 つ選ぶ（または Claude の推しを OK する）→ 台本

## 作り方（試作 第 1 回で作った仕組み。2026-10-28）

- 長さ：**8 分を超える。10 分以上でもよい**（2026-10-28 利用者）。第 1 回は約 11 分 50 秒（本編の声）
- 台本：`radio/r<4 桁>_<収録日>.txt`（例 `radio/r0001_1028.txt`）。書き方は漫才と同じ記号に、ラジオだけのものを足した（台本の頭に説明）
  - `combo: radio`：A＝アフロ、B＝モヒカン（たとえ係）、C＝ボブ、D＝金髪ギャル（読み手）。声は `proto/voices.json` の `voicevox.combos.radio`
  - `topic: 今週の話題①　〇〇`：ここから次の話題（画面に見出し）／`「…」@news`：ニュースを読むところ（あんこもんのノーマルの声・字幕は青）／`ALL:` 4 人で同時に
  - 叩くツッコミ（`B!`）は使わない
  - 台本の頭に出典（媒体名と日付）を書く
- ショート（CM 風）：`radio/r<番号>_<日>_cm.txt`（頭の声）と `_cm_end.txt`（「続きは、本編で！」）

```bash
python proto/synth.py radio/r0001_1028.txt --backend voicevox       # 本編の声（と _cm・_cm_end も）
python proto/vv_kana.py radio/r0001_1028.txt                         # 読みを確かめる
python proto/radio.py r0001_1028                                     # 本編（build/anim/r0001_1028.mp4。--frames 5,60 で静止画）
python proto/radio_cm.py r0001_1028 "ブロッコリーです" "植木鉢の下" "マロンもこが気になります"   # ショート（見どころにするセリフの一部を 3 つ）
```

- 画面：ラジオブース（吸音パネルの壁・調整室の窓・ON AIR のランプ・机の前に番組名）に、漫才と同じ 4 人の絵を机の後ろに並べる。左からアフロ・モヒカン・ギャル・ボブ。話している人は口が動いて少し弾む。下に字幕の枠（声に合わせて字を出す。話し手を三角で指す）
- 音：頭に出囃子、話している間は小さく出囃子をくり返す、話題の変わり目に短い合図

## 試作の手順

1. 話題を 4 つ選び、6〜8 分の台本を 1 本書く（声を作る前に利用者が読む）
2. ラジオブースの背景と 4 人の並べ方を描き、口パクの静止画を確かめる
3. 出来を見て、続けるか・番組名の字・出す曜日を決める
