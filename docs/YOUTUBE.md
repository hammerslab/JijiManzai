# YouTube に上げる手順

BlackFairyTales（毒入り童話）の `docs/PLAN.md`「YouTube 向けの決まり」「YouTube 投稿の手順」を元にした。違うところは ★ を付けた。
**動画を作る・上げるのは、利用者が言ったときだけ**。作るものは Claude が作り、YouTube Studio での入力と公開の判断は利用者がする。

## 2. 1 本ごとの手順

1. **台本**：`scripts/<番号>_<名前>.txt` を書き（番号は KEYWORDS.md のキーワードと同じ。内部の管理用で、YouTube の題名には入れない）、利用者が `.md` で読んで OK を出す（`docs/SCRIPT_GUIDE.md`）
2. **声**：`python proto/synth.py scripts/<番号>_<名前>.txt --backend voicevox` → 読みを `proto/vv_kana.py` で確かめ、利用者が聴いて OK を出す
3. **動画**：`python proto/render.py <番号>_<名前>` → `build/anim/<番号>_<名前>.mp4`
4. **最終チェック**（Claude が確かめて報告し、最後の判断は利用者）
   - 映像：タイトル・登場・吹き出し・叩くところ・見つめ合う・退場・エンディングのコマを目で見る（吹き出しのはみ出し、顔への重なり、絵の崩れ）
   - 音：読み間違い・音量・音割れ（`max_volume` が -1dB 前後）。聴くのは利用者
   - 内容：★ 時事の事実（数字・日付）が作った時点で正しいか。実在の人物・企業・商品名が出ていないか。人を傷つける言い方がないか
   - 権利：★ VOICEVOX のクレジットを、使ったキャラ全員分そろえたか（`docs/VOICEVOX.md`）
5. **アップロード**（YouTube Studio・手動）
   - **タイトル**：★「題名【ほのぼの漫才】お題」の形（例：退屈できない男【ほのぼの漫才】ドパガキ）。大事な部分は前の 30 字に。★ 「時事」という言葉は使わない（2026-10-20 利用者。[CHANNEL.md](CHANNEL.md)）
   - **説明**：1 行目にお題の短い説明（検索に掛かるように）。そのあとにクレジット：
     ```
     音声：VOICEVOX:麒ヶ島宗麟、VOICEVOX:白上虎太郎、VOICEVOX:ちび式じい
     ```
     （その回で使ったキャラだけ。Voidoll を使ったら「VOICEVOX:Voidoll(CV:丹下桜)」）
   - **タグ**：お題、漫才、アニメ漫才、お笑い、ほのぼの漫才劇場、など
   - **サムネイル**：★ 電話番号の確認が済むまで、自分の画像は入らない（2026-10-20 M-1 で入らなかった）。`python proto/thumbnail.py <番号>_<名前>` で 3 案（`build/<番号>_<名前>/thumbnail_1〜3.png`）。「テストと比較」にかける。文句は台本の頭の `thumb:`
   - **設定**：子ども向けではない、カテゴリ＝コメディ、動画の言語＝日本語、有料プロモーション＝いいえ、再生リスト、終了画面。
   - ★ **ショート動画は再生リストに入れない**（2026-10-21 利用者）。再生リストは本編だけ
   - ★ **再生リストはジャンルで分ける**（2026-10-20 利用者「お任せ」）。その回で初めて使うリストは、アップロードのときに作る
     - 世の中・エンタメの話題：M-1、台風、ハラスメント（作った）
     - 流行語・ネットの話題（作った）：チャッピー構文、ドパガキ、インフルエンサー、メロい、ミーム、フレネミー、映え、推し活、炎上
     - 食べもの・くらしの話題（作った）：麻辣湯、ドバイチョコ、シール帳、米の値段、ポイ活
     - AI・テクノロジーの話題（作った）：ハッカー（不正アクセス）、AI失業、空飛ぶクルマ
     「AI の使用」＝いいえ（実在の人・実際の映像・写実的な場面・主役の音楽のどれにも当たらない。毒入り童話と同じ判断。迷ったら利用者に聞く）
   - ★ **字幕は上げない**（ネタバレになる）。YouTube が自動で付ける字幕は、Studio の「字幕」で非公開にできるか確かめる
6. **公開**：★ **最初の 5 本は 2026-10-20 から毎日**（1 本目は M-1）。そのあとは **月曜・金曜の 19 時に予約公開**が基本。**水曜は直近の話題の回を上げる枠として空けておく**（週 2〜3 本。2026-10-22 利用者）。予約済み：0007 は 2026-10-26 19:00（https://youtu.be/ADiiGlzVyOo）、0008 は 2026-11-06 19:00（https://youtu.be/_bFLyxcsG38。2026-10-22 利用者：10/28 から移した）。0073 新NISA は 2026-10-28（水）19:00（https://youtu.be/GhLiOoRHFrw）、0074 音楽生成AI は 2026-11-04（水）19:00 に予約済み（2026-10-22 利用者）。★ 2026-10-22 利用者「残りの作成済みの動画も月水金で登録」：11/9 から月・水・金 19:00 に 1 本ずつ（予定表は build/work/schedule_rest.json。季節・鮮度のある回（二季・長袖・台風・酒税・円高）を前に、ふるさと納税は 12 月、防災は元日を避けた）。→ 2026-10-22 に 41 本すべて予約済み（11/9 の 0006 から 2027/2/10 の 0048 まで。日付は KEYWORDS.md の各行の「動画：」）。0040 と 0041 だけは、選ばれたファイルの都合で日付が入れ替わった（0041 は 1/27、0040 は 1/29）。★ 2026-10-23 利用者の指定で、さらに 6 組の日付を入れ替えた（督促状 0022⇄ハッカー 0006、献立表 0025⇄円高 0045、台風 0013⇄インフルエンサー 0005、データセンター 0035⇄メロい 0009、自転車 0043⇄炎上 0012、暗証番号 0041⇄ハラスメント 0017）。日付は KEYWORDS.md の「動画：」が最新。アップロードの手順は build/work/yt.py（youtube.txt から値を取る）と set_date.py（KEYWORDS.md に日付を足す）。ショートは各本編の公開の翌日 12:00、0011 は 2026-10-30 19:00（https://youtu.be/1hU4hVnVH7w）。0002 のショートは 2026-10-22 12:00。**毎日 19 時**（日本時間）に予約公開。M-1 は 2026-10-20 19:00（https://youtu.be/myWTxrNe4b4）、チャッピー構文は 2026-10-21 19:00（https://youtu.be/rD53412sceE）、ドパガキは 2026-11-02 19:00（2026-10-22 利用者：10/22 の枠は 0072 PHP の脆弱性と差し替え。0072 は 2026-10-22 19:00 に予約済み https://youtu.be/aypA9-Mcm-A）（https://youtu.be/_5NKkyXKG…）、麻辣湯は 2026-10-23 19:00（https://youtu.be/twz3WGzmpzg）、インフルエンサーは 2026-10-24 19:00（https://youtu.be/CEotyIW_WO8）に予約済み。最初の 5 本はここまで。ショートは本編の公開後に上げ、関連動画に本編を付けて翌日 12:00 に予約する（M-1 のショートは 2026-10-21 12:00 に予約済み、関連動画は付けた、再生リストには入れない）。固定コメントは付けない（2026-10-26 利用者：視聴者がまだ少なく、効果が小さいので手間をかけない。M-1 だけ投稿・固定済み）。時事は鮮度が大事なので、作ったら早めに出す。ショートは本編の公開のあとに
7. **上げたら KEYWORDS.md を直す**：そのキーワードの行に、動画の公開日時（ショートも上げたらそのあとにショートの公開日時）を書く。書き方は `scripts/README.md`

## 3. 動画の形式（mp4）

YouTube の推奨に合わせて `proto/render.py` が書き出す：

| 項目 | 中身 |
|---|---|
| 入れ物 | MP4（先頭に目次を置く `+faststart`） |
| 映像 | H.264（High）・1920×1080・30fps・yuv420p。GOP は 15 コマ |
| 音 | AAC・48kHz・ステレオ・192kbps。-1dB で割れ止め |
| 長さ | 漫才は 3 分以内。タイトル〜エンディングまでで 3 分半ほど |

（2026-10-20 に音を 48kHz ステレオにした。それより前に作った `0003_dopagaki.mp4` は 24kHz モノラル。上げる前に作り直すか、音だけ差し替える）

## 4. YouTube 向けの決まり

- **冒頭**：最初の数秒で離脱させない。いまはタイトル（3.5 秒）→ 登場（3.3 秒）→ 漫才。★ 毒入り童話のように「見せ場を先に 3 秒見せる」かは要検討
- **終了画面**：最後の 5〜20 秒に置ける。★ いまのエンディング（約 34 秒）は、真ん中に名場面、左右の下に 2 人、下にボタンと字幕があり、終了画面の要素（おすすめ動画・チャンネル登録）を置く場所がない。**最後の 15〜20 秒は左右か下を空ける**ように直す（まだ）
- **チャプター**：3 分の動画では付けない（0:00 から 3 つ以上・各 10 秒以上の条件を満たしにくく、ネタの区切りを見せるとネタバレにもなる）
- ★ **ショートは毎週月曜の作業で、先週に公開した本編の分をまとめて上げる**（2026-10-22 利用者「毎週月曜としましょう」。公開済みの本編のショートは、予約せずその場で公開してよい）（2026-10-22 利用者「いっぺんに上げず、週 1 回、先週分を上げる感じで」）。下書きは `python build/work/mk_short.py`（`build/<番号>_<名前>/youtube_short.txt`。公開は本編の翌日 12:00、再生リストなし、関連動画は本編）。0072 だけは 2026-10-22 20:40 に即公開で上げた（関連動画に本編を付けた。公開済みの本編のショートは、編集ページの「公開設定」を「公開」にし、「関連動画」の鉛筆から本編を選んで保存する）
- **ショート動画**：本編と一緒に作る。`python proto/short.py <番号>_<名前>` → `build/anim/<番号>_<名前>_short.mp4`（縦 1080×1920・1 分以内）。あいさつの次から 2 回目の叩くツッコミまでを切り出し（オチは見せない）、最後に「続きは本編で」のカード。区間は台本の頭の `short: 秒-秒` で変えられる。本編を先に公開し、ショートの関連動画に本編を付ける

## 5. 収益化で注意すること

1. **「子ども向け」に分類されないようにする**：かわいい 2D のアニメは子ども向けと誤判定されやすい。アップロード時に「子ども向けではない」を選ぶ
2. **「不自然なコンテンツ」ポリシー**：テンプレートで量産したように見える動画は収益化の対象外。★ 形（舞台・コンビ・エンディング）は毎回同じなので、**ネタ・題材・構成を毎回変える**（`docs/SCRIPT_GUIDE.md` の型と技を使い分ける）。台本は人が読んで OK を出す
3. ★ **時事の正確さ**：数字や日付の間違いは信頼を落とす。作る直前に確かめる。古くなった回は説明に「〇年〇月時点」と書く
4. ★ **VOICEVOX の規約**：政治・宗教・特定の個人や国への批判は使えない声がある（`docs/VOICEVOX.md`）。クレジットは必ず書く。チャンネルを会社として運営するなら、申請が要る声がある
5. **尺**：途中に入る広告は 8 分以上から。3 分の漫才では入らない。★ 数本まとめた長尺版（「ほのぼの漫才まとめ」）で補うかは要検討

## 6. まだ作っていない仕組み（上げる前に要る）

- 概要欄・タイトル・タグの下書き（`youtube.txt`）を自動で作る。VOICEVOX のクレジットは台本で使った声から自動で並べる
- エンディングの最後に、終了画面のための空き
