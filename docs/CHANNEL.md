# チャンネル「ほのぼの漫才劇場」

- 名前：ほのぼの漫才劇場（2026-10-20 利用者が決定）
- アイコン・バナー：`assets/channel/icon.png`・`banner.png`（`python art/gen_channel.py`）
- 作り方と設定の手順は [YOUTUBE.md](YOUTUBE.md)

## 概要説明（2026-10-20 決定：案 C。2026-10-22 に「週2〜3本更新」へ変更。「時事」という言葉は使わない）

```
ニュースはちょっと疲れる。でも、話題にはついていきたい。
そんなあなたに、3分の漫才を。

ほのぼの漫才劇場では、2組のコンビが、いま気になる言葉を
やさしく、くだらなく、漫才にします。
知らない言葉でも大丈夫。漫才の最初に、ちゃんと説明します。

週2〜3本更新／ショート動画も更新中

※キャラクターの声は音声合成（VOICEVOX）です。
```

- ほかの案（A：やさしく短く、B：コンビの紹介を前に）は使わないので消した

## 書くときの注意

- 「子ども向けではない」設定にするが、内容は誰が見ても大丈夫なものなので、「大人向け」とはあえて書かない（毒入り童話との違い）
- 音声合成であることは、概要説明にも 1 行書いておく（各動画の説明には、使ったキャラ全員の「VOICEVOX:キャラ名」を必ず書く）
- 公開は月・金の 19 時が基本で、水曜は直近の話題の回を入れる枠（週 2〜3 本。2026-10-22 利用者）。ショートは本編の翌日 12 時
- チャンネルのキーワード（設定 → チャンネル → 基本情報）：漫才、アニメ漫才、お笑い、流行語、話題、ほのぼの漫才劇場
- **「時事」「時事ネタ」「時事漫才」という言葉は、チャンネルの見た目と説明には使わない**（2026-10-20 利用者。もっとふんわりした言い方にする。バナーの副題は「気になる話題を、ゆるっと漫才に」）
