## 1 県ごとにやること
1. **調べる**（WebSearch）：その県の名物・名所・日本一を 5〜8 個と、よく知られた方言の語尾 2〜3 個。**自治体・観光協会・新聞・辞典など確かな出どころで確かめる**。確かめられなかったものは使わない。順位（日本一など）は「いまも」そうか確かめる（古い記事の日本一は、いまは 2 位のことがある）
2. **台本** `scripts/<番号>_<名前>.txt`
   - 頭のコメント：お題・コンビ・型（ボケのきっかけ × 方言／名物のずらし。サブの並び）・オチ・使った技・**事実（調べた時点と出どころ）**・気をつけたこと（手本と同じ形）
   - `combo:`（割り当てどおり）、`title:`（**県名で始める**。15 字くらいまで。「〜男」「〜女」）、`theme:`（「〇〇県」）、`thumb:`（3 案。`／` で区切り、`｜` で改行。1 行 8 字くらいまで）、**`banner: 〇〇県`**
   - **ボケのきっかけは県ごとに変える**（観光大使になりたい・移住したい・県民になりきる・その県の名物を全部やりたい・旅行の計画を立てすぎる・ふるさと自慢をしたい、など）。どれも同じ「観光大使」にしない。サブは名物などを 3〜5 個、しょぼい → 大きいへ。オチは前半の何かの回収にする
   - **方言は語尾だけ**、話すのはボケ（外から来た人のまね）。使いすぎ・まぜすぎ・場面に合わない使い方をボケにし、ツッコミが正しい意味・使い方を一言で直す（方言の豆知識になる）。方言をからかう向きにしない（好きでまねしている）。伸ばし棒は 1 本、漢字の方言は `{表示|読み}`
   - 尺は**声で 2 分 30 秒〜3 分**（3 分を超えたら一番弱いくだりを外す）。叩くツッコミ `B!` は 5〜8 回、最後のオチを `B!!!` に、後ろほど強く。見つめ合うは 0〜2 回、`「」@スタイル` の別の声は 0〜3 回
   - 最初の 30 秒以内に、ツッコミがその県の短い紹介（どこにあって、何が有名か）を言う
   - **県のほうはちゃんとしている側**。「何もない」「地味」「どこ」「ランキング下位」、県民性の悪口、過疎はいじらない。災害（震災・原発・水害など）にはふれない。実在の店・会社・商品名・ゆるキャラの名前・有名な歌や映画・本の題名は出さない（名物は「〇〇そば」のような一般の名前で）。政治・宗教にふれない（お寺・神社は観光地としてなら名前を出してよいが、からかわない）
3. **エンディング** `scripts/<番号>_<名前>_end.txt`（手本と同じ形。ボケのひとこと 3 つだけ、その回のネタにかける）
4. 作ったファイルは**すぐに `git add`**（commit はしない。`index.lock` のエラーが出たら少し待ってやり直す。`git add scripts/*` のようにまとめて add せず、自分のファイルだけ）
5. **声**：`python -X utf8 proto/synth.py scripts/<番号>_<名前>.txt --backend voicevox` と `_end.txt`。長さと「長すぎる声」の警告を見る
6. **読み**：`python -X utf8 proto/vv_kana.py scripts/<番号>_<名前>.txt scripts/<番号>_<名前>_end.txt` → `build/kana/<番号>_<名前>.txt` を全行読んで、**地名・名物・方言の読み**を特に確かめる。直すのは台本の中の `{表示|読み}` か言い回しで（共通の読み替えリスト `Z:/git/Movie/BlackFairyTales/tools/config.json` と `proto/voices.json` は編集しない。よくある語の読み間違いは報告に書く）。直したら声を作り直す
7. **読む用の md**：`python -X utf8 proto/script_md.py scripts/<番号>_<名前>.txt scripts/<番号>_<名前>_end.txt` → `.md` も `git add`
8. **説明文** `build/<番号>_<名前>/youtube.txt` と `youtube_short.txt`（`build/0116_saga/` の 2 つと同じ形。これは git に入るので `git add` する）
   - 本編の題名：`<title>【ほのぼの漫才】<theme>`。ショート：`<theme>！ <title> #shorts`
   - 説明の 1 行目：その県の短い紹介（名物など。調べた事実だけ）＋「そんな〇〇県を、ゆるっと漫才にしました。」。2 行目：「〜するアフロのボケと、モヒカンのツッコミの漫才です。」（女性は「ボブのボケと、ギャルのツッコミ」）。ショートの 2 行目は「続きは本編で。」
   - ハッシュタグ：`#漫才 #お笑い #ほのぼの漫才劇場 #<県名> #47都道府県`（ショートは最後に `#shorts`）
   - クレジット：男性は `音声：VOICEVOX:麒ヶ島宗麟、VOICEVOX:白上虎太郎`、女性は `音声：VOICEVOX:波音リツ、VOICEVOX:あんこもん`。`@robot`・`@system` を使ったら `、VOICEVOX:Voidoll(CV:丹下桜)`、`@jii` は `、VOICEVOX:ちび式じい`、`@shibui` は `、VOICEVOX:†聖騎士 紅桜†`
