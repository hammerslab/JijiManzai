# VOICEVOX のキャラの利用規約（2026-10-20 に調べた）

時事漫才の動画（自作のキャラ絵が話す・収益化する予定）で使う前提で、候補 14 キャラの規約を読んだ結果。
規約は変わることがあるので、使う前に規約ページをもう一度見る。

## 全体（VOICEVOX ソフトの規約 https://voicevox.hiroshiba.jp/term/ ）

- 商用・非商用とも可。ただし、作った音声には**キャラごとの規約**がかかる
- **「VOICEVOX:キャラ名」のクレジットが必要**。迷ったら概要欄に、使った全員を並べる（Voidoll だけは「VOICEVOX:Voidoll(CV:丹下桜)」）

## この企画での注意

1. **政治・宗教・特定の個人や国への批判は、どのキャラでも避ける**（漫才の決まり「人を傷つけない」と同じ向き）。時事ネタで一番引っかかりやすい
2. **自作キャラの声にしてよいと明記しているのは**、波音リツ・†聖騎士 紅桜†・VirVox の 5 人（雀松朱司・青山龍星・麒ヶ島宗麟・白上虎太郎・玄野武宏）だけ。ほかは規約に書いていない（禁止とも書いていない）。気になるなら明記のあるキャラから選ぶ
3. **チャンネルを会社や個人事業として運営するなら**：青山龍星は事前申請、Voidoll は原則使えない、No.7 と猫使アルは事前相談。個人のチャンネルなら、どのキャラも申請なしで収益化できる読み
4. 栗田まろんは、規約ページが読めるようになってから確かめる
5. エンドロールや概要欄に「VOICEVOX:〇〇」を使った全員分入れる（動画の形に、まだ入れていない）
